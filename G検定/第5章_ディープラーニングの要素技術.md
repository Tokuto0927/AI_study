# G検定 第5章「ディープラーニングの要素技術」合格ノート

## 0. この章のゴール

第5章のゴールは、ディープラーニングで使われる代表的なネットワーク構成要素を、**名前だけでなく「何をする層か」「何と混同しやすいか」「試験でどう問われるか」**まで押さえること。

特にG検定では、以下が頻出。

| 分野 | 最重要ポイント |
|---|---|
| CNN | 畳み込み層、フィルタ、ストライド、パディング、プーリング、スキップ結合 |
| RNN | 時系列データ、LSTM、GRU、BPTT、教師強制、露出バイアス |
| Attention / Transformer | Self-Attention、Q/K/V、Multi-Head Attention、位置エンコーディング |
| オートエンコーダ | 入力を再構成する教師なし学習、エンコード・デコード、VAE |
| 章末問題対策 | Random Erasing、データ拡張、GRU、Transformerの特徴 |

---

## 1. 全体像

第5章は、ディープラーニングの「部品カタログ」。

ざっくり言うと、以下の対応で覚える。

| 技術 | 主に扱うデータ | 何をするか |
|---|---|---|
| CNN | 画像 | 局所的な特徴を抽出する |
| 畳み込み層 | 画像・特徴マップ | フィルタで特徴を抽出する |
| プーリング層 | 特徴マップ | サイズを小さくし、特徴を集約する |
| 全結合層 | 抽出済み特徴 | 最終的な分類・判定につなげる |
| スキップ結合 | 深いネットワーク | 勾配を伝わりやすくする |
| 正規化層 | 各層の特徴 | 学習を安定させる |
| RNN | 時系列・文章・音声 | 過去の情報を現在の処理に使う |
| LSTM / GRU | 長い時系列 | RNNの勾配消失や重み衝突を緩和する |
| Attention | 系列データ | どの入力を重視するか学習する |
| Transformer | 自然言語など | RNNを使わずAttention中心で系列を処理する |
| オートエンコーダ | 画像・特徴表現 | 入力を圧縮し、再構成する |

## 2. 重要用語・概念

### 2.1 畳み込み層

| 項目 | 内容 |
|---|---|
| 意味 | フィルタ、またはカーネルを入力データ上で動かし、特徴マップを作る層 |
| 試験での押さえ方 | 「フィルタで局所特徴を抽出」「CNNの中心要素」と覚える |
| 間違えやすい点 | フィルタの値は人間が手で決めるのではなく、学習で獲得される |

畳み込み処理は、画像の一部に小さなフィルタを重ね、対応する値同士を掛けて足し合わせる処理。

| 用語 | 意味 | 試験ポイント |
|---|---|---|
| フィルタ / カーネル | 特徴を抽出する小さな行列 | 「小領域」「特徴抽出」で出る |
| 特徴マップ | 畳み込み処理の結果 | 入力画像から得られた特徴の地図 |
| チャネル | RGBなどの入力の奥行き方向 | 入力がH×W×Nならフィルタも奥行きNを持つ |

---

### 2.2 パディング

| 項目 | 内容 |
|---|---|
| 意味 | 入力データの周囲に0などを追加する処理 |
| 試験での押さえ方 | 「畳み込み後のサイズ縮小を防ぐため」と覚える |
| 間違えやすい点 | ストライドやプーリングと混同しやすい |

畳み込みをすると、通常は特徴マップのサイズが小さくなる。  
入力と同じサイズを保ちたい場合に、上下左右へ0を追加する。

| 処理 | 目的 |
|---|---|
| パディング | 周囲に値を追加し、出力サイズを調整する |
| ゼロパディング | 周囲を0で埋める代表的な方法 |

---

### 2.3 ストライド

| 項目 | 内容 |
|---|---|
| 意味 | フィルタをずらす幅 |
| 試験での押さえ方 | 「移動幅」と出たらストライド |
| 間違えやすい点 | スライド、ストロークなどの選択肢に惑わされない |

| ストライド | 動き | 特徴マップサイズ |
|---|---|---|
| 1 | 1画素ずつ動かす | 比較的大きい |
| 2以上 | 飛ばしながら動かす | 小さくなる |

試験ではほぼこの形で問われる。

| 問われ方 | 正解 |
|---|---|
| CNNでフィルタを移動させる幅 | ストライド |
| CNNで入力の周囲に0を埋める処理 | パディング |
| CNNで小領域を動かして特徴を抽出するもの | フィルタ / カーネル |

---

### 2.4 Atrous Convolution / Dilated Convolution

| 項目 | 内容 |
|---|---|
| 意味 | フィルタの要素間に間隔を空けて畳み込みを行う処理 |
| 試験での押さえ方 | 「受容野を広げるが、計算量を大きく増やさない」 |
| 間違えやすい点 | フィルタサイズ自体を単純に大きくする処理ではない |

Atrous Convolutionは、別名Dilated Convolution。  
広い範囲の情報を見たいが、パラメータ数や計算量を増やしたくない場合に使う。

| 通常の畳み込み | Atrous / Dilated Convolution |
|---|---|
| フィルタを密に適用 | フィルタの間隔を空けて適用 |
| 見る範囲が狭い | 広い範囲を見られる |
| 単純 | 受容野を広げやすい |

---

### 2.5 Depthwise Separable Convolution

| 項目 | 内容 |
|---|---|
| 意味 | 空間方向とチャネル方向の畳み込みを分ける軽量化手法 |
| 試験での押さえ方 | 「通常の畳み込みより計算量を削減する」と覚える |
| 間違えやすい点 | 通常の畳み込みと完全に同じ精度・処理ではない |

| 処理 | 内容 |
|---|---|
| Depthwise Convolution | チャネルごとに空間方向の畳み込みを行う |
| Pointwise Convolution | 1×1畳み込みでチャネル方向を混ぜる |
| Depthwise Separable Convolution | 上記2つを組み合わせ、計算量を削減する |

試験では「軽量化」「計算量削減」「チャネルごと」「1×1畳み込み」が出たら反応する。

---

### 2.6 プーリング層

| 項目 | 内容 |
|---|---|
| 意味 | 特徴マップを小さくする処理 |
| 試験での押さえ方 | 「ダウンサンプリング」「サブサンプリング」と同義で押さえる |
| 間違えやすい点 | プーリング層には学習すべきパラメータがない |

| 種類 | 内容 |
|---|---|
| 最大値プーリング | 小領域内の最大値を取り出す |
| 平均値プーリング | 小領域内の平均値を取り出す |

プーリングの効果は以下。

| 効果 | 内容 |
|---|---|
| 特徴次元の削減 | データサイズを小さくする |
| 位置ずれへの頑健性 | 少し位置がずれても特徴を捉えやすくする |
| 不変性の獲得 | 入力の微小変化に強くなる |

---

### 2.7 全結合層

| 項目 | 内容 |
|---|---|
| 意味 | 入力された特徴に重みをかけて総和を取り、出力につなげる層 |
| 試験での押さえ方 | CNNでは畳み込み・プーリング後の分類部分で使われる |
| 間違えやすい点 | 畳み込み層のように局所特徴を抽出する層ではない |

CNNでは、畳み込み層・プーリング層で特徴を抽出し、最後に全結合層で分類する構成が基本。

| 処理 | 役割 |
|---|---|
| 畳み込み層 | 特徴抽出 |
| プーリング層 | 特徴の集約・縮小 |
| 全結合層 | 分類・判定 |

なお、全結合層の代わりにGlobal Average Poolingが使われることもある。

---

### 2.8 スキップ結合

| 項目 | 内容 |
|---|---|
| 意味 | 層を飛び越えて情報を伝える結合 |
| 試験での押さえ方 | 「ResNet」「勾配消失問題の緩和」とセットで覚える |
| 間違えやすい点 | ドロップアウトやリカレント結合ではない |

深いネットワークでは、誤差が入力層近くまで伝わりにくくなる。  
スキップ結合は、層を飛び越えるルートを作ることで、誤差を伝わりやすくする。

| 用語 | 内容 |
|---|---|
| スキップ結合 | 層を飛び越える結合 |
| ResNet | スキップ結合を導入した代表的モデル |
| 勾配消失問題 | 深い層で誤差が伝わりにくくなる問題 |

章末問題では「ResNet」「層をまたぐ結合」「誤差の逆伝播を行いやすい」が出たら、正解はスキップ結合。

---

### 2.9 正規化層

| 項目 | 内容 |
|---|---|
| 意味 | 各層に伝わる特徴の分布を整える層 |
| 試験での押さえ方 | 「平均0、分散1に近づけ、学習を安定化」と覚える |
| 間違えやすい点 | 正則化と正規化を混同しない |

| 用語 | 対象 | 覚え方 |
|---|---|---|
| バッチ正規化 | ミニバッチ内のデータ間で正規化 | batch単位 |
| レイヤー正規化 | データごとに全チャネルをまとめて正規化 | layer単位 |
| インスタンス正規化 | データごと・チャネルごとに正規化 | instance単位 |
| グループ正規化 | データごとに複数チャネルをグループ化して正規化 | group単位 |

正規化層は、学習をうまく進めやすくし、過学習を抑える効果もある。

---

### 2.10 RNN

| 項目 | 内容 |
|---|---|
| 意味 | 過去の中間状態を次の入力処理に利用するニューラルネットワーク |
| 試験での押さえ方 | 「時系列データ」「自然言語」「音声」「再帰構造」とセット |
| 間違えやすい点 | CNNは画像、RNNは時系列と押さえる |

RNNは、過去の情報を保持しながら次の処理を行う。  
言語モデルでは、過去の単語列から次の単語を予測する。

| ネットワーク | 得意なデータ |
|---|---|
| DNN | 一般的な表形式・特徴量データ |
| CNN | 画像など空間構造を持つデータ |
| RNN | 文章・音声・時系列データ |

---

### 2.11 エルマンネットワークとジョルダンネットワーク

| 用語 | 内容 | 主な利用例 |
|---|---|---|
| エルマンネットワーク | 回帰結合層の情報を次時刻に伝える | 自然言語処理など |
| ジョルダンネットワーク | 出力層の情報を次時刻に伝える | ロボットの運動制御など |

試験で細かく出る可能性は低めだが、「RNNにも種類がある」と押さえておく。

---

### 2.12 LSTM

| 項目 | 内容 |
|---|---|
| 意味 | RNNの勾配消失問題や重み衝突を緩和する手法 |
| 試験での押さえ方 | 「セル」「入力ゲート」「出力ゲート」「忘却ゲート」 |
| 間違えやすい点 | LSTMはCNNではなくRNN系の手法 |

LSTMは、RNNが苦手とする長期依存関係を扱うために作られた。

| 構成要素 | 役割 |
|---|---|
| セル | 誤差を内部に保持し、勾配消失を防ぐ |
| 入力ゲート | 必要な入力情報を取り込む |
| 出力ゲート | 必要な情報を出力する |
| 忘却ゲート | 不要な情報を捨てる |

| RNNの問題 | LSTMでの対応 |
|---|---|
| 勾配消失 | セルにより誤差を保持 |
| 入力重み衝突 | 入力ゲートで制御 |
| 出力重み衝突 | 出力ゲートで制御 |
| 不要情報の蓄積 | 忘却ゲートでリセット |

---

### 2.13 GRU

| 項目 | 内容 |
|---|---|
| 意味 | LSTMを簡略化し、計算量を減らしたRNN系手法 |
| 試験での押さえ方 | 「LSTMよりゲートが少ない」「計算コスト削減」 |
| 間違えやすい点 | AdamやBPTTとは別物 |

| 手法 | 特徴 |
|---|---|
| LSTM | 入力ゲート・出力ゲート・忘却ゲートを持つ |
| GRU | リセットゲート・更新ゲートを持つ |
| BPTT | RNNの学習方法 |
| Adam | 最適化手法 |

章末問題では「LSTMの高い計算コストを削減」「ゲート数を削減」と出たらGRU。

---

### 2.14 Bidirectional RNN

| 項目 | 内容 |
|---|---|
| 意味 | 過去方向と未来方向の両方から系列を読むRNN |
| 試験での押さえ方 | 「過去と未来の両方を使う」と覚える |
| 間違えやすい点 | リアルタイム予測で常に使えるわけではない |

たとえば文章中の単語の品詞推定では、前の単語だけでなく後ろの単語も見たほうが精度が上がる。

---

### 2.15 エンコーダ・デコーダ / Seq2Seq

| 項目 | 内容 |
|---|---|
| 意味 | 入力系列をエンコードし、出力系列をデコードするモデル |
| 試験での押さえ方 | 「機械翻訳」「入力系列と出力系列の長さが違ってもよい」 |
| 間違えやすい点 | 入力1つに出力1つではなく、系列から系列を扱う |

| 役割 | 内容 |
|---|---|
| エンコーダ | 入力データを処理して符号化する |
| デコーダ | 符号化された情報から出力を生成する |
| Seq2Seq | sequence-to-sequence、系列から系列への変換 |

機械翻訳では、入力文と翻訳文の長さが一致しないためSeq2Seqが使われる。

---

### 2.16 BPTT

| 項目 | 内容 |
|---|---|
| 意味 | BackPropagation Through-Timeの略。RNNで時間方向に誤差を逆伝播する学習方法 |
| 試験での押さえ方 | 「RNNの学習」「時間軸に沿った誤差逆伝播」 |
| 間違えやすい点 | GRUやLSTMのようなモデル名ではなく、学習方法 |

RNNは過去の情報を現在に反映するため、誤差も過去にさかのぼって伝える必要がある。

---

### 2.17 教師強制

| 項目 | 内容 |
|---|---|
| 意味 | 訓練時に、前時刻の正解データを次の入力として使う方法 |
| 試験での押さえ方 | 「訓練時は正解を次入力に使える」と覚える |
| 間違えやすい点 | テスト時には正解データを使えない |

| フェーズ | 次の入力に使うもの |
|---|---|
| 訓練時 | 正解データ |
| テスト時 | 1つ前のモデル出力 |

---

### 2.18 露出バイアス

| 項目 | 内容 |
|---|---|
| 意味 | 訓練時とテスト時で入力の傾向が異なり、性能が落ちる問題 |
| 試験での押さえ方 | 「教師強制の副作用」と覚える |
| 間違えやすい点 | 過学習そのものとは違う |

教師強制では、訓練時は正解データを次の入力に使う。  
しかしテスト時は正解がないため、モデル自身の出力を次の入力に使う。  
このズレにより、繰り返し、矛盾、ハルシネーションなどの一因になる。

---

### 2.19 Attention

| 項目 | 内容 |
|---|---|
| 意味 | 複数の入力のうち、どこを重視するかを学習する仕組み |
| 試験での押さえ方 | 「重要度」「重み」「単語間の関連性」 |
| 間違えやすい点 | Attentionの可視化だけで完全に説明可能になるわけではない |

Attentionは、過去の各時刻の状態に重みを付け、その重み付き和を使って出力を計算する。

| 例 | Attentionの役割 |
|---|---|
| 機械翻訳 | 出力単語を作るとき、入力文のどの単語を重視するか |
| Image Captioning | 説明文生成時、画像のどこに注目するか |
| NLP全般 | 単語ベクトル間の関連性を捉える |

章末問題では「複数の単語ベクトルに対して、どのベクトルを重視するかを学習」と出たらAttention。

---

### 2.20 Transformer

| 項目 | 内容 |
|---|---|
| 意味 | RNNを使わず、Attentionを中心に構成されたEncoder-Decoderモデル |
| 試験での押さえ方 | 「RNNを排除」「Self-Attention」「並列計算」「遠い単語関係を捉える」 |
| 間違えやすい点 | 並列計算できない、という選択肢は誤り |

Transformerは、RNNの欠点を解決するために登場した。

| RNNの課題 | Transformerでの解決 |
|---|---|
| 逐次処理が必要で遅い | Self-Attentionにより並列計算しやすい |
| 遠い単語間の関係が薄れやすい | 全単語間の関係を直接計算できる |
| 長文の情報保持が難しい | Attentionで重要な関係を直接参照できる |

---

### 2.21 Self-Attention

| 項目 | 内容 |
|---|---|
| 意味 | 同じ系列内の要素同士の関連度を計算するAttention |
| 試験での押さえ方 | 「入力文内」「出力文内」「自分自身との関係」と覚える |
| 間違えやすい点 | Source-Target Attentionと混同しない |

| Attentionの種類 | 何の関係を見るか |
|---|---|
| Self-Attention | 同じ文・同じ系列内の単語同士 |
| Source-Target Attention | 入力文と出力文の単語同士 |
| Encoder-Decoder Attention | Source-Target Attentionとほぼ同じ意味で使われる |

TransformerのEncoder側で使われるAttentionはSelf-Attention。

---

### 2.22 位置エンコーディング

| 項目 | 内容 |
|---|---|
| 意味 | 単語の位置情報を入力に加える仕組み |
| 試験での押さえ方 | 「Self-Attentionは語順を失いやすいので、位置情報を足す」 |
| 間違えやすい点 | 計算コストを小さくするためではない |

Self-Attentionは全単語間の関係を直接見るため、RNNのように順番に読むわけではない。  
そのままだと語順情報が弱くなるため、位置エンコーディングを付加する。

章末問題では「位置エンコーディングにより、時系列データの並列処理が可能」とされる。

---

### 2.23 Query / Key / Value

| 項目 | 内容 |
|---|---|
| 意味 | Attention計算に使う3種類のベクトル |
| 試験での押さえ方 | 「Qで問い合わせ、Kと照合し、Vを重み付けして取り出す」 |
| 間違えやすい点 | Q/K/VはTransformerだけでなくAttention計算の基本概念 |

| 用語 | イメージ |
|---|---|
| Query | 何を探したいか |
| Key | 何に該当するかを照合するための見出し |
| Value | 実際に取り出す情報 |

Self-Attentionでは、Query・Key・Valueはすべて同じ系列から作られる。  
Source-Target Attentionでは、Queryはデコーダ側、KeyとValueはエンコーダ側から作られる。

---

### 2.24 Multi-Head Attention

| 項目 | 内容 |
|---|---|
| 意味 | 複数のAttentionを並列に計算する仕組み |
| 試験での押さえ方 | 「複数の視点で関係を見る」と覚える |
| 間違えやすい点 | 単にAttentionを1回行うだけではない |

| 用語 | 意味 |
|---|---|
| Head | 1つのAttention計算単位 |
| Multi-Head Attention | 複数のHeadで異なる関係性を捉える |

たとえば文中の単語関係を見るとき、あるHeadは主語と動詞の関係、別のHeadは修飾関係を捉えるようなイメージ。

---

### 2.25 オートエンコーダ

| 項目 | 内容 |
|---|---|
| 意味 | 入力と出力が同じになるように学習するネットワーク |
| 試験での押さえ方 | 「入力を圧縮して再構成」「教師なし学習」 |
| 間違えやすい点 | 分類ラベルを使う教師あり学習ではない |

| 構成 | 内容 |
|---|---|
| 入力層 | 元データを入力 |
| 隠れ層 | 入力の圧縮表現 |
| 出力層 | 入力を再構成 |

オートエンコーダのポイントは、隠れ層の次元を入力層より小さくすること。  
これにより、重要な情報だけを圧縮して保持するように学習する。

| 処理 | 内容 |
|---|---|
| エンコード | 入力を隠れ層の圧縮表現に変換する |
| デコード | 圧縮表現から元の入力を再構成する |

応用例として、画像のノイズ除去などがある。

---

### 2.26 積層オートエンコーダ

| 項目 | 内容 |
|---|---|
| 意味 | オートエンコーダを順番に学習し、積み重ねる手法 |
| 試験での押さえ方 | 「事前学習」「ディープラーニング黎明期」と覚える |
| 間違えやすい点 | 現在の主流手法ではない |

| 用語 | 内容 |
|---|---|
| 積層オートエンコーダ | 複数のオートエンコーダを重ねる |
| 事前学習 | 各層を順番に学習して重みを初期化する |

現在では「事前学習」という言葉は、主に転移学習や基盤モデルの文脈で使われることが多い。

---

### 2.27 変分オートエンコーダ

| 項目 | 内容 |
|---|---|
| 意味 | 入力を潜在変数の確率分布に変換し、そこからデータを生成するモデル |
| 試験での押さえ方 | 「VAE」「平均と分散」「潜在変数」「生成モデル」とセット |
| 間違えやすい点 | 通常のオートエンコーダは圧縮表現、VAEは分布として表現 |

| モデル | 隠れ表現の扱い |
|---|---|
| 通常のオートエンコーダ | 入力を圧縮表現にする |
| VAE | 入力を平均・分散で表される統計分布にする |

VAEでは、エンコーダが入力を潜在変数の分布に変換し、デコーダがその分布からサンプリングしてデータを生成する。

| 関連手法 | 内容 |
|---|---|
| VQ-VAE | 潜在変数を離散値にする |
| infoVAE | 潜在変数とデータの相関を高める |
| β-VAE | 潜在空間上で特徴を分離しやすくする |

| 項目 | 内容 |
|---|---|
| 意味 | 画像の一部領域をランダムな値に変更するデータ拡張手法 |
| 試験での押さえ方 | 「画像処理」「データ拡張」「一部分をランダムに消す」 |
| 間違えやすい点 | ドロップアウト、マスク言語モデル、枝刈りと混同しない |

章末問題で出ているため押さえる。

| 選択肢に出やすい説明 | 正誤 |
|---|---|

| ニューロンをランダムに除外する | ドロップアウト |
| 文中の単語をマスクして予測する | マスク言語モデル |
| 推論に影響の少ない接続を削除する | 枝刈り |

## 3. 重要論点の整理

### 3.1 CNNの基本処理の流れ

CNNは画像認識でよく使われる。

| 順番 | 処理 | 役割 |
|---|---|---|
| 1 | 畳み込み層 | フィルタで局所特徴を抽出 |
| 2 | 活性化関数 | 非線形性を加える |
| 3 | プーリング層 | 特徴を集約し、サイズを小さくする |
| 4 | 全結合層 | 分類・判定を行う |

試験では「CNNは自然言語処理と強化学習のみに適する」は誤り。  
CNNは特に画像認識で重要。

---

### 3.2 畳み込み層・プーリング層・全結合層の違い

| 層 | 学習パラメータ | 役割 | キーワード |
|---|---:|---|---|
| 畳み込み層 | あり | 特徴抽出 | フィルタ、カーネル、特徴マップ |
| プーリング層 | なし | 特徴集約・サイズ縮小 | 最大値、平均値、ダウンサンプリング |
| 全結合層 | あり | 分類・判定 | フラット化、重み付き和 |

特に「プーリング層には学習すべきパラメータがない」は狙われやすい。

---

### 3.3 深いネットワークで必要になる工夫

| 問題 | 対策 |
|---|---|
| 勾配消失 | ReLU、スキップ結合、LSTMなど |
| 学習の不安定化 | 正規化層 |
| 過学習 | ドロップアウト、正則化、データ拡張、正規化 |
| 計算量増大 | Depthwise Separable Convolution、GRU、モデル軽量化 |

第5章では特に、スキップ結合、正規化層、GRUが重要。

---

### 3.4 RNN系モデルの整理

| モデル | 目的 | 重要ポイント |
|---|---|---|
| RNN | 時系列処理 | 過去の中間状態を使う |
| LSTM | 長期依存の処理 | セルと3つのゲート |
| GRU | LSTMの軽量化 | リセットゲート・更新ゲート |
| BiRNN | 前後文脈の利用 | 過去と未来の両方を見る |
| Seq2Seq | 系列から系列への変換 | エンコーダ・デコーダ |
| Attention付きSeq2Seq | 長文対応 | 重要な入力を重み付け |

---

### 3.5 Transformerの整理

TransformerはRNNを使わず、Attentionを中心にした構造。

| 要素 | 内容 |
|---|---|
| Encoder | 入力系列を処理する |
| Decoder | 出力系列を生成する |
| Self-Attention | 同じ系列内の単語関係を見る |
| Source-Target Attention | 入力系列と出力系列の関係を見る |
| 位置エンコーディング | 語順情報を補う |
| Multi-Head Attention | 複数視点でAttentionを計算する |

試験では以下が出やすい。

| 問い | 答え |
|---|---|
| TransformerのEncoder側で使われるAttention | Self-Attention |
| TransformerがRNNより高速に学習しやすい理由 | 並列計算しやすいから |
| Self-Attentionで失われやすい情報 | 語順情報 |
| 語順情報を補う仕組み | 位置エンコーディング |

---

## 4. 似た用語の違い

### 4.1 パディング・ストライド・プーリング

| 用語 | 何をするか | 試験での識別ワード |
|---|---|---|
| パディング | 入力の周囲に0などを追加する | 周囲に埋める、サイズ維持 |
| ストライド | フィルタを動かす幅 | 移動幅、ずらす幅 |
| プーリング | 特徴マップを小さくする | 最大値、平均値、ダウンサンプリング |

---

### 4.2 フィルタ・特徴マップ・チャネル

| 用語 | 意味 |
|---|---|
| フィルタ / カーネル | 特徴を抽出するための小さな行列 |
| 特徴マップ | フィルタを適用して得られる出力 |
| チャネル | RGBなどの奥行き方向の情報 |

---

### 4.3 最大値プーリング・平均値プーリング

| 用語 | 内容 |
|---|---|
| 最大値プーリング | 小領域の最大値を取る |
| 平均値プーリング | 小領域の平均を取る |

どちらもプーリング層であり、学習パラメータはない。

---

### 4.4 スキップ結合・ドロップアウト・リカレント結合

| 用語 | 内容 | 混同注意 |
|---|---|---|
| スキップ結合 | 層を飛び越えて情報を伝える | ResNet |
| ドロップアウト | ニューロンをランダムに無効化 | 過学習抑制 |
| リカレント結合 | 過去の状態を次時刻に渡す | RNN |

---

### 4.5 LSTM・GRU・BPTT・Adam

| 用語 | 種類 | 内容 |
|---|---|---|
| LSTM | RNNモデル | セルと3ゲートで長期依存を扱う |
| GRU | RNNモデル | LSTMを簡略化し計算量を削減 |
| BPTT | 学習方法 | 時間方向に誤差逆伝播 |
| Adam | 最適化手法 | 勾配降下法の改良系 |

---

### 4.6 Attention・Self-Attention・Source-Target Attention

| 用語 | 見る関係 |
|---|---|
| Attention | 入力のどこを重視するか |
| Self-Attention | 同じ系列内の要素同士 |
| Source-Target Attention | 入力系列と出力系列の要素同士 |

---

### 4.7 オートエンコーダ・VAE・GAN

| 用語 | 内容 |
|---|---|
| オートエンコーダ | 入力を圧縮し、再構成する |
| VAE | 入力を潜在変数の分布に変換し、生成に使う |
| GAN | 生成器と識別器を競わせて生成する |

第5章ではGANそのものより、オートエンコーダとVAEが中心。

### 5.1 CNNまわり

| 引っかけ選択肢 | なぜ誤りか |

### 9.2 落としやすいポイント

|---|---|

| 位置エンコーディングを計算量削減と覚える | 目的は語順・位置情報の付与 |
| データ拡張を学習時間短縮と覚える | データ増加なので短縮目的ではない |

## 10. 最短復習用まとめ

第5章は、以下だけまず覚える。

### 10.1 画像系

| 用語 | 最短理解 |
|---|---|
| CNN | 画像特徴を抽出するネットワーク |
| 畳み込み | フィルタで特徴マップを作る |
| パディング | 周囲に0を足す |
| ストライド | フィルタの移動幅 |
| プーリング | 特徴マップを小さくする |
| スキップ結合 | ResNet、勾配を伝えやすくする |
| Random Erasing | 画像の一部をランダムに変更するデータ拡張 |

---

### 10.2 時系列系

| 用語 | 最短理解 |
|---|---|
| RNN | 過去の状態を使う |
| LSTM | 長期依存に強いRNN |
| GRU | LSTMの軽量版 |
| BiRNN | 過去と未来の両方を見る |
| BPTT | 時間方向の誤差逆伝播 |
| 教師強制 | 訓練時に正解を次入力へ |
| 露出バイアス | 訓練時とテスト時の入力ズレ |

---

### 10.3 Transformer系

| 用語 | 最短理解 |
|---|---|
| Attention | どこを重視するか |
| Self-Attention | 同じ系列内の関係を見る |
| Query / Key / Value | 問い合わせ・照合・取り出す情報 |
| Multi-Head Attention | 複数視点のAttention |
| Transformer | RNNなし、Attention中心、並列計算しやすい |
| 位置エンコーディング | 語順情報を付ける |

---

### 10.4 生成・圧縮系

| 用語 | 最短理解 |
|---|---|
| オートエンコーダ | 入力を圧縮し、再構成 |
| エンコード | 圧縮 |
| デコード | 復元 |
| 積層オートエンコーダ | オートエンコーダを重ねる |
| VAE | 潜在変数の分布から生成 |

### 10.5 最後の一言

第5章は、用語数は多いけど、構造はシンプル。

- 画像ならCNN
- 時系列ならRNN
- 長期依存ならLSTM / GRU
- 重要な入力を選ぶならAttention
- RNNなしで高速に系列を扱うならTransformer
- 入力を圧縮・再構成するならオートエンコーダ
- 分布から生成するならVAE

試験では「名前」よりも、「何を解決するための技術か」で聞かれる。
だから、各技術を以下の形で覚える。

| 技術 | 解決したい問題 |
|---|---|
| パディング | 畳み込み後のサイズ縮小 |
| ストライド | フィルタの移動幅調整 |
| プーリング | 特徴量の集約・次元削減 |
| スキップ結合 | 深い層での勾配伝播 |
| 正規化 | 学習の安定化 |
| LSTM | RNNの勾配消失・長期依存 |
| GRU | LSTMの計算量 |
| Attention | 長い系列で重要情報を選ぶ |
| Transformer | RNNの逐次処理・長距離依存 |
| 位置エンコーディング | Self-Attentionの語順情報不足 |
| オートエンコーダ | 重要特徴の圧縮表現 |
| VAE | 潜在分布からのデータ生成 |
