# G検定 第6章「ディープラーニングの応用例」合格ノート

## 0. この章のゴール

第6章は、ディープラーニングを「どの分野で、どのモデル・技術が、何のために使われるか」を問う章。

この章で狙われるのは、数式よりも以下の対応関係。

| 覚える軸 | 試験での問われ方 |
|---|---|
| タスク名 | 物体認識・物体検出・セグメンテーション・姿勢推定などの違い |
| 代表モデル | AlexNet、VGG、GoogLeNet、ResNet、YOLO、SSD、U-Net、BERT、GPT、DQNなど |
| 仕組み | CNN、Attention、事前学習、転移学習、GAN、Diffusion、蒸留、量子化など |
| 引っかけ | 「分類なのか」「位置検出なのか」「画素単位なのか」「双方向なのか」「軽量化手法なのか」 |

この章は範囲が広いけど、全部を深く理解しようとしすぎると沼る。
G検定ではまず「用語と用途の対応」を固めるのが勝ち筋。

## 1. 全体像

第6章は、ディープラーニングの応用分野を横断的に扱う。

| 分野 | 中心テーマ | 頻出度 | 押さえ方 |
|---|---|---:|---|
| 画像認識 | CNN、物体認識、物体検出、セグメンテーション、姿勢推定 | 高 | タスクの違いと代表モデルを対応させる |
| 音声処理 | A-D変換、FFT、MFCC、音声認識、音声合成 | 中 | 変換順序・特徴量・WaveNetを押さえる |
| 自然言語処理 | BoW、TF-IDF、word2vec、GPT、BERT、LLM | 高 | 「語順を考慮する/しない」「一方向/双方向」を区別 |
| 深層強化学習 | DQN、経験再生、AlphaGo、AlphaZero、OpenAI Five | 中 | 強化学習＋DNN、ゲームAI、実世界応用の課題 |
| データ生成 | GAN、DCGAN、Pix2Pix、CycleGAN、Diffusion、NeRF | 高 | 生成モデル同士の違いを押さえる |
| 転移学習・ファインチューニング | 学習済みモデル、Few-shot、自己教師あり、継続学習 | 高 | 転移学習とファインチューニングの違い |
| マルチモーダル | CLIP、DALL-E、基盤モデル | 中 | 画像＋テキストなど複数形式の扱い |
| 解釈性 | XAI、CAM、Grad-CAM、LIME、SHAP | 中 | CAMとGrad-CAMの制約の違い |
| 軽量化 | 蒸留、枝刈り、量子化 | 高 | 何を削る/圧縮するかで区別 |

## 2. 重要用語・概念

### 2.1 画像認識

| 用語 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| RGB画像 | 赤・緑・青の3チャネルを持つ画像 | 画像は縦・横・チャネルの3次元データ | 単なる2次元データと考えない |
| チャネル | 画像の奥行き方向の情報 | RGBなら3チャネル | 幅・高さとは別軸 |
| CNN | 画像の位置関係を保ったまま処理するニューラルネットワーク | 画像処理の基本モデル | 全結合だけだと画像の空間構造が失われる |
| 畳み込み層 | 局所的な特徴を抽出する層 | エッジ・模様・形状などを抽出 | 全体分類を直接する層ではない |
| プーリング層 | 特徴マップを縮小し、位置ずれに強くする層 | 代表値を取って情報を圧縮 | パラメータを学習する層ではない |
| ネオコグニトロン | 福島邦彦らによる初期のCNN的モデル | S細胞層・C細胞層 | LeNetと構造は似るが学習法が違う |
| LeNet | ヤン・ルカンによる初期CNN | 畳み込み層＋プーリング層＋誤差逆伝播 | ネオコグニトロンとは学習法が異なる |
| データ拡張 | 既存データを変換して擬似的に増やす | 反転・回転・拡大縮小・ノイズ・Cutout・Mixupなど | 意味が変わる変換は不適切 |

### 2.2 画像認識モデル

| モデル | 何のモデルか | 特徴 | 試験での押さえ方 |
|---|---|---|---|
| AlexNet | 物体認識 | ILSVRC 2012で注目。DLブームの象徴 | CNNが画像認識で圧勝した代表例 |
| VGG / VGG16 | 物体認識 | 3×3畳み込みを積み重ねるシンプル構造 | 層が深くなるほど特徴マップは小さく、数は多くなる |
| GoogLeNet | 物体認識 | Inceptionモジュール | 複数サイズの畳み込みを組み合わせる |
| ResNet | 物体認識 | スキップ結合で超深層化 | 「畳み込み層のみ」ではない。スキップ結合が重要 |
| SENet | 物体認識 | Attentionで特徴マップに重み付け | Attention機構をCNNへ導入 |
| MobileNet | 軽量CNN | Depthwise Separable Convolutionで軽量化 | モバイル・エッジ向け |
| EfficientNet | 高精度・効率モデル | NAS系の考え方と関連 | 転移学習でも有用 |
| NAS | ネットワーク構造探索 | 人手でなく学習により構造探索 | モデルそのものというより探索手法 |

### 2.3 画像タスクの違い

| タスク | 入力 | 出力 | 代表例 | 試験でのキーワード |
|---|---|---|---|---|
| 物体認識 | 画像 | 画像全体のクラス | 猫画像 → 猫 | クラス分類 |
| 物体検出 | 画像 | 物体クラス＋矩形位置 | 人がどこにいるか | バウンディングボックス、矩形領域 |
| セマンティックセグメンテーション | 画像 | 画素ごとのクラス | 道路・空・車を画素単位分類 | 同一クラスは区別しない |
| インスタンスセグメンテーション | 画像 | 個体ごとの画素領域 | 人A・人Bを分ける | 個体ごとに分離 |
| パノプティックセグメンテーション | 画像 | 背景＋個体を統合的に分類 | 道路は一括、人は個体別 | セマンティック＋インスタンス |
| 姿勢推定 | 画像 | 関節位置・骨格 | 頭・肩・肘・膝など | 信頼度マップ、OpenPose |

### 2.4 物体検出モデル

| モデル | 種類 | 仕組み | 試験での押さえ方 |
|---|---|---|---|
| R-CNN | 2段階モデル | Selective Searchで候補領域抽出 → CNN → SVM | 候補領域ごとに処理するので遅い |
| Fast R-CNN | 2段階モデル | 画像全体から特徴マップ作成 → RoIプーリング | R-CNNより高速 |
| Faster R-CNN | 2段階モデル | Selective SearchをRPNに置換 | RPNで候補領域生成 |
| YOLO | 1段階モデル | 画像をグリッドに分け、物体らしさと矩形を直接出力 | 高速。You Only Look Once |
| SSD | 1段階モデル | 複数の特徴マップとデフォルトボックスを利用 | 小物体対策、複数スケール |

### 2.5 セグメンテーションモデル

| モデル | タスク | 特徴 | 試験での押さえ方 |
|---|---|---|---|
| FCN | セマンティックセグメンテーション | 全結合層を使わず畳み込み層で構成 | Fully Convolutional Network |
| SegNet | セマンティックセグメンテーション | エンコーダ・デコーダ構造、プーリング位置を利用 | 境界をぼやけにくくする |
| U-Net | セマンティックセグメンテーション | エンコーダ側特徴をデコーダ側へコピー | 医療画像で有名 |
| PSPNet | セマンティックセグメンテーション | Pyramid Pooling Module | 複数解像度で特徴を捉える |
| DeepLab / DeepLabV3 | セマンティックセグメンテーション | Atrous convolution / Dilated convolution | 章末問題頻出。DeepLabV3＝Atrous |
| Mask R-CNN | インスタンスセグメンテーション | Faster R-CNN＋マスク推定 | 物体検出＋セグメンテーション |

### 2.6 音声処理

| 用語 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| A-D変換 | アナログ音声をデジタルに変換 | 標本化 → 量子化 → 符号化 | 順番が頻出 |
| PCM | 音声をデジタル化する代表方式 | パルス符号変調 | A-D変換とセットで出る |
| FFT | 音声を周波数スペクトルへ変換 | 高速フーリエ変換 | 音声そのものを生成する手法ではない |
| メル尺度 | 人間の聴覚特性に合わせた尺度 | 低周波に敏感、高周波に鈍感 | Hzそのものではない |
| スペクトル包絡 | 周波数スペクトルの大まかな形 | 音色を表す | フォルマント周波数と混同注意 |
| MFCC | スペクトル包絡を求める代表的特徴量 | 音声認識・話者識別で使う | 「音色特徴」として押さえる |
| フォルマント | スペクトル包絡のピーク | 音韻の特徴に関係 | MFCCそのものではない |
| STT | Speech-to-Text | 音声認識 | 音声 → テキスト |
| TTS | Text-to-Speech | 音声合成 | テキスト → 音声 |
| WaveNet | DeepMindの音声合成モデル | 2016年、音声合成の質向上 | DQN/AlexNet/ResNetと混同しない |

### 2.7 音声認識モデル

| 構成要素 | 役割 | 試験での押さえ方 |
|---|---|---|
| 音響モデル | 音声信号と音素列の対応確率を扱う | HMM、GMM、CNN、RNNなど |
| 言語モデル | 単語列の自然さ・出現確率を扱う | n-gram、RNN、Transformerなど |
| 辞書 | 単語と音素列の対応を持つ | 音声認識の構成要素 |
| HMM | 音響モデルの古典的手法 | 隠れマルコフモデル |
| CTC | 入力系列と出力系列の長さ違いに対応 | 空文字・同一音素の縮約がキーワード |
| End-to-End音声認識 | 音声から直接単語列を生成 | 音響・言語モデルをまとめる流れ |

### 2.8 自然言語処理

| 用語 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 自然言語 | 人間が日常的に使う言語 | プログラミング言語と区別 | NLPの対象 |
| n-gram | n個の単位を並べたもの | uni-gram、bi-gram、tri-gram | 単語だけでなく文字・音素にも使う |
| BoW | 単語の出現回数で文書を表す | 語順を考慮しない | 「語順を考慮する」は誤り |
| Bag-of-n-grams | n-gramをBoW的に扱う | 局所的な語順を多少反映 | BoWより語順情報が入る |
| one-hotベクトル | 1次元だけ1、他は0の表現 | 高次元・疎・局所表現 | 意味の近さは表せない |
| TF-IDF | 単語の重要度を表す指標 | 文書内で多く、他文書に少ない単語が高い | 単なる出現回数ではない |
| 分散表現 | 低次元・密な実数ベクトル | 単語の意味の近さを表せる | one-hotと対比 |
| word2vec | 分散表現を得る代表手法 | 分布仮説、skip-gram、CBOW | BoWとは違う |
| skip-gram | 中心単語から周辺単語を予測 | word2vecの一種 | CBOWと逆 |
| CBOW | 周辺単語から中心単語を予測 | word2vecの一種 | skip-gramと逆 |
| fastText | 部分文字列も考慮した単語埋め込み | OOVに強い | word2vecの拡張系 |
| ELMo | 文脈を考慮した分散表現 | 多義語に対応しやすい | word2vecは基本的に単語ごとに1表現 |

### 2.9 GPT・BERT・LLM

| モデル | 開発元 | 構造 | 学習の特徴 | 試験での押さえ方 |
|---|---|---|---|---|
| GPT | OpenAI | Transformerのデコーダ系 | 過去の単語列から次単語予測 | 一方向・生成系 |
| BERT | Google | Transformerのエンコーダ系 | MLMとNSP | 双方向・理解系 |
| GPT-2 / GPT-3 | OpenAI | GPTの大規模化 | パラメータ増大で生成能力向上 | LLMの流れ |
| ALBERT / DistilBERT | BERT系軽量化 | パラメータ削減 | 精度を保ちつつ軽量化 | 大規模モデルの圧縮 |
| ChatGPT | OpenAI | LLM応用 | RLHFで人間のフィードバックを活用 | RLHFがキーワード |
| ViT | Google系研究 | Transformerを画像へ応用 | CNNを使わない画像モデル | Vision Transformer |

#### GPTとBERTの違い

| 観点 | GPT | BERT |
|---|---|---|
| 主な用途 | 文章生成 | 文章理解・分類 |
| Transformer構造 | デコーダ系 | エンコーダ系 |
| 参照方向 | 過去方向のみ。一方向 | 文全体。双方向 |
| 事前学習 | 次単語予測 | MLM、NSP |
| 試験の引っかけ | 「双方向」と書かれたらGPTではない | 「一方向」と書かれたらBERTではない |

### 2.10 自然言語処理タスク

| タスク | 内容 | 試験での押さえ方 |
|---|---|---|
| 形態素解析 | 文を単語のような単位に分割 | 基礎解析 |
| 構文解析 | 形態素間の関係を解析 | 文構造を求める |
| 情報検索 | 検索エンジンなど | 文書検索 |
| 文書要約 | 長文を短くまとめる | 生成・抽出の両方あり |
| 機械翻訳 | ある言語から別の言語へ変換 | LLMやNMTと関連 |
| 対話システム | 会話応答 | ChatGPTなど |
| 感情分析 | ポジティブ/ネガティブ判定 | 文書分類の一種 |
| 自然言語推論 | 2文の矛盾・含意を判定 | NLI/RTE |
| 質問応答 | 文書に基づいて答える | SQuADなど |
| GLUE | 言語理解タスクのベンチマーク | SuperGLUE、JGLUEも関連 |

### 2.11 深層強化学習

| 用語 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 深層強化学習 | 強化学習にDNNを組み合わせた手法 | 画像など高次元状態を扱える | 教師あり学習ではない |
| DQN | Deep Q-Network | DeepMind、Atariで有名 | Q学習＋DNN |
| 経験再生 | 過去の経験を保存しランダムに再利用 | 学習を安定化 | 時系列順にそのまま学習しない |
| ターゲットネットワーク | 過去のネットワークを教師的に使う | 価値推定を安定化 | 現在のネットワークだけでは不安定 |
| Rainbow | DQN拡張を組み合わせた手法 | Double DQN、Dueling、優先度付き経験再生など | 単独の新概念というより統合手法 |
| モデルフリー強化学習 | 環境モデルを明示的に学習しない | DQNなど | 環境予測モデルなし |
| モデルベース強化学習 | 環境の予測モデルを利用 | サンプル効率改善が期待 | モデルフリーと区別 |
| 世界モデル | 周囲の世界の予測モデルを学習する枠組み | モデルベース系の重要概念 | LLMの「世界知識」とは別文脈 |
| sim2real | シミュレータで学習し現実へ転移 | ロボット制御で重要 | リアリティギャップに注意 |
| ドメインランダマイゼーション | シミュレータ条件をランダム化 | sim2realのギャップ対策 | 単なるデータ拡張とは文脈が違う |
| 残差強化学習 | 既存制御との差分をRLで学習 | 安全性・効率性向上 | 一から全部RLで学ぶわけではない |
| オフライン強化学習 | 固定データセットから方策学習 | 実環境探索リスクを減らす | オンラインRLと区別 |
| 模倣学習 | 人間のデモから学ぶ | デモンストレーションがキーワード | 報酬付きデータから改善するオフラインRLとは違う |

| 用語 | 意味 | 試験での押さえ方 |
|---|---|---|
| モンテカルロ木探索 | ランダムシミュレーションで良い手を近似 | AlphaGoと関連 |

### 2.13 データ生成

| 用語 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 生成タスク | 新しいデータを作るタスク | 画像・音声・文章生成 | 分類タスクではない |
| 潜在空間 | データの背後にある特徴空間 | 画像生成などで重要 | 画像そのものではない |
| VAE | 変分オートエンコーダ | 生成モデルの一種 | GANとは構造が違う |
| GAN | 敵対的生成ネットワーク | GeneratorとDiscriminatorが競う | 教師ネットワーク・生徒ネットワークではない |
| Generator | 偽物データを生成 | 偽札作り側 | Discriminatorと逆にしない |
| Discriminator | 本物/偽物を識別 | 警官側 | Generatorと逆にしない |
| DCGAN | CNNを使ったGAN | 高解像度画像生成に貢献 | CNNを用いるGAN |
| Pix2Pix | 画像から別画像への変換 | ペア画像が必要 | CycleGANと違う |
| CycleGAN | ペア画像なしで変換 | 循環的に元画像へ戻す制約 | Pix2Pixと混同注意 |
| Diffusion Model | ノイズ除去で生成するモデル | 拡散過程・逆拡散過程 | GANのような敵対構造ではない |
| NeRF | 複数視点画像から3Dシーン生成 | 新視点画像も生成可能 | 画像分類モデルではない |

### 2.14 転移学習・ファインチューニング

| 用語 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 学習済みモデル | 大規模データで事前学習されたモデル | ImageNet学習済みモデルなど | 一から学習しない |
| 転移学習 | 既存モデルを使い、主に出力層だけ学習 | 出力層を新タスク用に変更 | 全層更新ではない |
| ファインチューニング | 学習済みモデルを初期値にして全体も更新 | 全層または多くの層を再学習 | 転移学習より更新範囲が広い |
| Few-shot学習 | 少数例で学習・推論 | 数枚・数例 | 大量教師データ不要 |
| One-shot学習 | 1例で学習・推論 | Few-shotより少ない | Zero-shotと違う |
| Zero-shot学習 | 例を与えず指示だけで実行 | CLIPやLLMで頻出 | 学習データがゼロという意味ではない |
| MAML | 学習方法自体を学ぶメタ学習 | Model-Agnostic Meta-Learning | 単なるファインチューニングではない |
| 半教師あり学習 | ラベルあり＋ラベルなしデータを使う | 擬似ラベル、一致性正則化 | 教師なし学習ではない |
| FixMatch | 擬似ラベル＋一致性正則化 | 弱い拡張と強い拡張 | 半教師あり学習の手法 |
| 自己教師あり学習 | 正解ラベルなしでプレテキストタスクを解く | マスク予測、ジグソーパズルなど | 教師なしに近いが目的タスクを自作する |
| 下流タスク | 事前学習後に解く本来の目的タスク | ファインチューニング対象 | 事前学習タスクと区別 |
| 継続学習 | 新しいクラス・環境に順次適応 | 破滅的忘却が課題 | 一度だけの転移学習ではない |
| 破滅的忘却 | 新しい学習で過去知識を忘れる | 継続学習の重要課題 | 過学習とは違う |

### 2.15 マルチモーダル・基盤モデル

| 用語 | 意味 | 試験での押さえ方 |
|---|---|---|
| マルチモーダル | 画像・音声・テキストなど複数形式を扱う | 異なるモダリティを統合 |
| Image Captioning | 画像から説明文を生成 | 画像 → テキスト |
| Text-to-Image | テキストから画像を生成 | テキスト → 画像 |
| CLIP | 画像特徴とテキスト特徴を近づけるモデル | Zero-shot分類が可能 |
| DALL-E | テキストから画像生成 | CLIPやDiffusionと関連 |
| 基盤モデル | 大量データで学習し多用途に使えるモデル | Flamingo、Unified-IOなど |

### 2.16 モデルの解釈性

| 用語 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| XAI | 説明可能AI | 判断根拠を説明する技術群 | 精度向上手法ではない |
| LIME | 局所的に線形モデルで近似して説明 | 機械学習全般で利用 | 画像専用ではない |
| Permutation Importance | 特徴量を入れ替えて寄与度を見る | 特徴量重要度 | DL専用ではない |
| SHAP | 特徴量の寄与度を測る | 説明手法 | CAMとは別 |
| CAM | 画像のどこを見たか可視化 | GAPを持つモデルで利用 | GAPが必要 |
| GAP | Global Average Pooling | CAMで重要 | Grad-CAMでは必須ではない |
| Grad-CAM | 勾配情報で判断根拠を可視化 | GAPなしモデルにも適用可能 | 「勾配を使わない」は誤り |
| Guided Grad-CAM | Grad-CAMの低解像度問題を改善 | より細かい特徴可視化 | Grad-CAMと同一ではない |

### 2.17 モデルの軽量化

| 手法 | 何をするか | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 蒸留 | 大きな教師モデルの知識を小さな生徒モデルへ移す | teacher / student、soft target | パラメータを直接削るわけではない |
| hard target | one-hotの正解ラベル | 通常の教師あり学習 | soft targetと対比 |
| soft target | 教師モデルの事後確率 | クラス間の類似情報を含む | 正解クラス以外も0ではない |
| 枝刈り / プルーニング | 不要な接続・重みを0にする | パラメータ削除 | 量子化ではない |
| マグニチュードベース | 絶対値の小さい重みを削除 | 枝刈りの方法 | 勾配を使わない |
| 勾配ベース | 感度の小さい重みを削除 | 枝刈りの方法 | 絶対値だけではない |
| 宝くじ仮説 | 良い初期値を持つサブネットワークがあるという考え | pruning後に初期値へ戻す | 単なるランダム削除ではない |
| 量子化 | パラメータを少ないビット数で表現 | 32bit → 8bitなど | 構造は変えずメモリ削減 |

## 3. 重要論点の整理

### 3.1 画像認識は「分類・位置・画素・骨格」で分ける

| 問われる表現 | 答えるべきタスク |
|---|---|
| 画像全体が何かを当てる | 物体認識 |
| 対象物の位置を矩形で特定 | 物体検出 |
| 画素単位でクラス分類 | セマンティックセグメンテーション |
| 同じクラスの個体も分離 | インスタンスセグメンテーション |
| 背景はクラス単位、物体は個体単位 | パノプティックセグメンテーション |
| 頭・肩・肘・膝などを推定 | 姿勢推定 |

### 3.2 CNNモデルの発展は「深くする工夫」と「軽くする工夫」

| 流れ | 代表モデル | ポイント |
|---|---|---|
| 初期CNN | LeNet | 畳み込み＋プーリング＋誤差逆伝播 |
| DLブーム | AlexNet | 2012年ILSVRCで圧勝 |
| シンプルに深く | VGG | 3×3畳み込みを積む |
| 幅広い特徴を同時に | GoogLeNet | Inceptionモジュール |
| 超深層化 | ResNet | スキップ結合 |
| Attention導入 | SENet | 特徴マップに重み付け |
| 軽量化 | MobileNet | Depthwise Separable Convolution |
| 構造探索 | NAS / EfficientNet | ネットワーク構造を探索 |

### 3.3 物体検出は2段階モデルと1段階モデル

| 種類 | 代表モデル | 特徴 |
|---|---|---|
| 2段階モデル | R-CNN、Fast R-CNN、Faster R-CNN | 候補領域を出してから分類 |
| 1段階モデル | YOLO、SSD | 位置とクラスを同時に推定し高速 |

#### R-CNN系の進化

| モデル | 違い |
|---|---|
| R-CNN | Selective Searchで候補領域を出し、候補ごとにCNN処理 |
| Fast R-CNN | 画像全体から特徴マップを作り、候補領域を切り出す |
| Faster R-CNN | 候補領域生成をRPNというCNNに置き換える |

### 3.4 セグメンテーションはモデル名と構造をセットで覚える

| モデル | キーワード |
|---|---|
| FCN | 全結合層なし、畳み込み層だけ |
| SegNet | エンコーダ・デコーダ、プーリングインデックス |
| U-Net | 医療画像、スキップ的なコピー |
| PSPNet | Pyramid Pooling Module |
| DeepLabV3 | Atrous convolution / Dilated convolution |
| Mask R-CNN | Faster R-CNN＋インスタンスセグメンテーション |

### 3.5 音声処理は「変換順」と「特徴量」が出る

#### A-D変換の順序

| 順番 | 処理 | 内容 |
|---:|---|---|
| 1 | 標本化 | 一定時間ごとに値を取る |
| 2 | 量子化 | 連続値を離散値に近似 |
| 3 | 符号化 | ビット列に変換 |

引っかけ：
- 「符号化 → 量子化 → 標本化」は誤り。
- 正しくは「標本化 → 量子化 → 符号化」。

### 3.6 音声認識と音声合成の対応

| 技術 | 入力 | 出力 | 英語表現 |
|---|---|---|---|
| 音声認識 | 音声 | テキスト | STT |
| 音声合成 | テキスト | 音声 | TTS |

### 3.7 NLPは表現方法の違いが頻出

| 表現 | 語順 | 意味の近さ | 次元 | 代表例 |
|---|---|---|---|---|
| BoW | 考慮しない | 弱い | 高次元 | 単語頻度 |
| one-hot | 考慮しない | 表せない | 高次元・疎 | 単語ID |
| 分散表現 | 文脈により扱える | 表せる | 低次元・密 | word2vec |
| 文脈化分散表現 | 文脈を考慮 | 多義語に強い | 低次元・密 | ELMo、BERT系 |

### 3.8 GPTとBERTは超頻出

| 問われ方 | 正解 |
|---|---|
| GPTは何を使うか | Transformerのデコーダ系 |
| GPTはどちら向きか | 一方向。過去から次単語を予測 |
| BERTは何を使うか | Transformerのエンコーダ |
| BERTはどちら向きか | 双方向 |
| BERTの事前学習 | MLM、NSP |
| GPT/BERTはword2vecと何が違うか | 事前学習と同じモデルで応用タスクを解ける |

### 3.9 深層強化学習はDQN中心

| 論点 | 押さえる内容 |
|---|---|
| DQN | Q学習にDNNを組み合わせる |
| なぜ必要か | 画像など状態数が膨大な場合、表形式Q学習では無理 |
| 経験再生 | 過去経験をランダムに再利用して学習安定化 |
| ターゲットネットワーク | 過去ネットワークを使って価値推定を安定化 |
| AlphaGo | MCTS＋深層強化学習 |
| AlphaGo Zero | 人間棋譜なし、自己対戦のみ |
| AlphaZero | 囲碁・将棋・チェスへ一般化 |
| 実世界応用 | サンプル効率、安全性、報酬設計、sim2realが課題 |

### 3.10 生成モデルは構造の違いで覚える

| モデル | 生成方法 | 覚え方 |
|---|---|---|
| VAE | 潜在空間から生成 | オートエンコーダ系 |
| GAN | 生成器と識別器を競わせる | 偽物作り vs 見抜く警官 |
| DCGAN | GANにCNNを利用 | 高解像度画像生成 |
| Pix2Pix | ペア画像で画像変換 | ペアあり |
| CycleGAN | ペアなし画像変換 | 元に戻す制約 |
| Diffusion | ノイズから徐々に復元 | 逆拡散 |
| NeRF | 複数視点から3Dシーン生成 | 新視点画像を生成 |

### 3.11 転移学習・ファインチューニングは更新範囲で区別

| 手法 | 更新する重み | 使う場面 |
|---|---|---|
| 転移学習 | 主に新しい出力層だけ | 小規模データで分類器を作る |
| ファインチューニング | 全層または多くの層 | 既存特徴だけでは足りない場合 |

### 3.12 軽量化は「知識を移す・削る・ビット数を減らす」

| 手法 | 何を軽くするか |
|---|---|
| 蒸留 | 大モデルの知識を小モデルへ移す |
| 枝刈り | 不要な接続・重みを削る |
| 量子化 | 重みの表現ビット数を減らす |

## 5. 試験で狙われる引っかけ

### 5.1 画像認識系

| 引っかけ文 | 判定 | 理由 |
|---|---|---|
| ResNetは畳み込み層のみを積み重ねたモデルである | 誤り | スキップ結合が重要 |
| GoogLeNetはInceptionモジュールを使う | 正しい | 複数サイズの畳み込みを組み合わせる |
| VGGは3×3畳み込みを多用する | 正しい | シンプルな深層CNN |
| MobileNetはモバイル向けに軽量化されている | 正しい | Depthwise Separable Convolution |
| ImageNetはモデル名である | 誤り | データセット |
| DeepLabV3は物体認識モデルである | 誤り | セマンティックセグメンテーション |
| DeepLabV3はAtrous convolutionを採用 | 正しい | 章末問題級 |
| Fast R-CNNは画像を細かく分割して個別にCNNへ入れる | 誤り寄り | R-CNNの説明に近い。Fast R-CNNは画像全体から特徴マップを得る |
| YOLOは2段階モデルである | 誤り | 1段階モデル |
| SSDはデフォルトボックスを使う | 正しい | 複数スケール特徴マップも重要 |

### 5.2 セグメンテーション系

| 引っかけ文 | 判定 | 理由 |
|---|---|---|
| セマンティックセグメンテーションは同じクラスの個体を分離できる | 誤り | 同一クラスはまとめる |
| インスタンスセグメンテーションは個体ごとに分離する | 正しい | 人A・人Bを分ける |
| PSPNetはPyramid Pooling Moduleを持つ | 正しい | セマンティックセグメンテーション |
| U-Netは医療画像で使われる | 正しい | X線、CT、MRIなど |
| Mask R-CNNはインスタンスセグメンテーションを行う | 正しい | Faster R-CNNにマスク推定を追加 |

### 5.3 音声処理系

| 引っかけ文 | 判定 | 理由 |
|---|---|---|
| A-D変換は符号化→量子化→標本化の順で行う | 誤り | 標本化→量子化→符号化 |
| MFCCはスペクトル包絡を求める代表的方法 | 正しい | 音色特徴を表す |
| フォルマント周波数はスペクトル包絡そのもの | 誤り | スペクトル包絡のピーク周波数 |
| WaveNetは音声合成モデル | 正しい | DeepMind、2016年 |
| DQNは音声合成モデル | 誤り | 深層強化学習 |
| STTはテキストから音声 | 誤り | 音声からテキスト |
| TTSはテキストから音声 | 正しい | 音声合成 |

### 5.4 NLP系

| 引っかけ文 | 判定 | 理由 |
|---|---|---|
| BoWは語順を考慮する | 誤り | 単語の出現回数中心 |
| TF-IDFは全文書に頻出する単語ほど高い | 誤り | 多くの文書に出る単語はIDFが低い |
| word2vecは単語の分散表現を得る | 正しい | 意味の近さを表せる |
| skip-gramは周辺単語から中心単語を予測 | 誤り | 中心単語から周辺単語 |
| CBOWは中心単語から周辺単語を予測 | 誤り | 周辺単語から中心単語 |
| GPTはTransformerのエンコーダを使う | 誤り | デコーダ系 |
| BERTは一方向のTransformerを使う | 誤り | 双方向 |
| BERTはMLMとNSPを使う | 正しい | 超頻出 |
| word2vecやELMoはGPT/BERTと同じ意味での事前学習モデルに含まれる | 基本は誤り | GPT/BERTは同じモデルで応用タスクまで解ける |

### 5.5 深層強化学習系

| 引っかけ文 | 判定 | 理由 |
|---|---|---|
| DQNは音声合成モデルである | 誤り | 深層強化学習 |
| DQNはQ学習にDNNを組み合わせた手法 | 正しい | Deep Q-Network |
| 経験再生は過去経験を保存してランダムに再利用する | 正しい | 学習安定化 |
| AlphaGo Zeroは人間の棋譜を使う | 誤り | 自己対戦のみ |
| AlphaZeroは囲碁だけに特化 | 誤り | 囲碁・将棋・チェスなど |
| sim2realではリアリティギャップが課題 | 正しい | シミュレータと現実の差 |
| オフライン強化学習は学習中に環境と相互作用し続ける | 誤り | 固定データセットから学習 |

### 5.6 生成モデル・転移学習・軽量化

| 引っかけ文 | 判定 | 理由 |
|---|---|---|
| GANは教師ネットワークと生徒ネットワークで構成 | 誤り | GeneratorとDiscriminator |
| Pix2Pixはペア画像が不要 | 誤り | ペア画像が必要 |
| CycleGANはペア画像なしでも変換できる | 正しい | 循環制約 |
| Diffusion Modelはノイズから徐々に画像を復元する | 正しい | 逆拡散 |
| NeRFは複数視点画像から3Dシーンを生成 | 正しい | 新視点生成も可能 |
| 転移学習は全層を更新する | 誤り寄り | 主に出力層を更新 |
| ファインチューニングは全層も更新する | 正しい | 学習済み重みを初期値にする |
| Zero-shotは例題を与える | 誤り | 指示のみ |
| 蒸留は不要な重みを0にする | 誤り | 知識を小モデルへ移す |
| 枝刈りは重みを0にする | 正しい | pruning |
| 量子化はビット数を削減する | 正しい | 32bit→8bitなど |

## 10. 最短復習用まとめ

### 10.1 1分復習

- CNNは画像の位置関係を保って処理できる。
- AlexNetは2012年の画像認識ブームの象徴。
- VGGは3×3畳み込み、GoogLeNetはInception、ResNetはスキップ結合。
- 物体認識は「何か」、物体検出は「何がどこか」、セグメンテーションは「画素ごと」。
- R-CNN系は2段階、YOLO/SSDは1段階。
- DeepLabV3はAtrous convolution、PSPNetはPyramid Pooling Module。
- A-D変換は標本化→量子化→符号化。
- MFCCは音色特徴、WaveNetは音声合成、CTCは音声認識の系列長不一致対策。
- BoWは語順を考えない単語頻度。
- GPTはデコーダ系・一方向、BERTはエンコーダ系・双方向・MLM/NSP。
- DQNは深層強化学習、AlphaGo Zeroは自己対戦のみ。
- GANは生成器と識別器、Diffusionはノイズ除去、NeRFは3Dシーン生成。
- 転移学習は主に出力層、ファインチューニングは全体も更新。
- CAMはGAPが必要、Grad-CAMは勾配情報。
- 蒸留は教師→生徒、枝刈りは重み削除、量子化はビット数削減。

### 10.3 最後の一言

第6章は「広くて苦しい章」だけど、G検定では深い実装よりも対応関係が勝負。

ここを外さなければ、第6章はかなり戦える。
