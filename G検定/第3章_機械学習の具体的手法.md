# G検定 第3章「機械学習の具体的手法」合格ノート

## 0. この章のゴール

第3章のゴールは、機械学習の代表的な手法について、以下を見分けられるようになること。

| ゴール | 試験で問われる形 |
|---|---|
| 教師あり学習・教師なし学習・強化学習の違いを説明できる | 「正解ラベルがあるか」「報酬を最大化するか」で分類させる |
| 回帰問題と分類問題を区別できる | 売上予測・株価予測・体重予測は回帰、画像分類・迷惑メール分類は分類 |
| 代表的なアルゴリズムの用途を選べる | 線形回帰、ロジスティック回帰、ランダムフォレスト、SVM、k-means、PCAなど |
| 評価指標を使い分けられる | 正解率、適合率、再現率、F値、ROC曲線、AUC |
| 過学習・交差検証・モデル複雑度を理解できる | 「訓練データでは高精度、未知データでは低精度」の原因を問う |
| 章末問題の定番パターンに対応できる | 用語の穴埋め、手法の説明、評価指標の選択問題 |

この章は、G検定ではかなり点を取りやすい章。
ただし、似た用語が多いので「名前」ではなく「何をする手法か」で覚えること。

## 1. 全体像

### 1-1. 機械学習の3分類

| 分類 | 何を学習するか | データの特徴 | 代表例 | 試験での見分け方 |
|---|---|---|---|---|
| 教師あり学習 | 入力と出力の関係 | 正解ラベルあり | 回帰、分類 | 「正解付きデータ」「予測」「分類」 |
| 教師なし学習 | データそのものの構造・特徴 | 正解ラベルなし | クラスタリング、PCA、協調フィルタリング | 「顧客層を分ける」「構造を見つける」 |
| 強化学習 | 行動の選び方 | 報酬あり | Q学習、方策勾配、Actor-Critic | 「報酬最大化」「エージェント」「環境」 |

### 1-2. 教師あり学習の問題タイプ

| 問題タイプ | 予測するもの | 例 | 代表手法 |
|---|---|---|---|
| 回帰問題 | 連続値 | 売上、価格、気温、株価、体重 | 線形回帰、リッジ回帰、ラッソ回帰、自己回帰モデル |
| 分類問題 | 離散値・カテゴリ | 犬/猫分類、迷惑メール判定、不良品判定 | ロジスティック回帰、SVM、決定木、ランダムフォレスト |

### 1-3. 教師なし学習の代表タスク

| タスク | 内容 | 代表手法 |
|---|---|---|
| クラスタリング | 似たデータをグループ分けする | k-means法、ウォード法、最短距離法 |
| 次元削減 | 多数の特徴量を少数の特徴量に圧縮する | 主成分分析、SVD、MDS、t-SNE |
| レコメンド | ユーザーや商品の類似性から推薦する | 協調フィルタリング、コンテンツベースフィルタリング |
| トピック推定 | 文書がどの話題に属するかを確率的に推定する | LDA |

### 1-4. 強化学習の基本構造

| 要素 | 意味 | 例：自動運転 |
|---|---|---|
| エージェント | 行動する主体 | 車 |
| 環境 | エージェントが置かれた世界 | 道路、信号、歩行者、他車 |
| 状態 | 環境から観測される情報 | 周囲の車、信号、速度 |
| 行動 | エージェントが選ぶ操作 | 進む、止まる、曲がる |
| 報酬 | 行動の良し悪しを示すスコア | 安全に進めたらプラス、事故ならマイナス |
| 方策 | 状態から行動を選ぶ戦略 | この状態ならブレーキ、など |

## 2. 重要用語・概念

### 2-1. 学習の種類

| 重要語句 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 教師あり学習 | 入力と正解出力のペアから、入力と出力の関係を学習する手法 | 「正解ラベルあり」「予測・分類」とセットで覚える | 教師あり＝人間が毎回教える、ではない |
| 教師なし学習 | 正解出力なしで、入力データの構造や特徴を学習する手法 | 「クラスタリング」「次元削減」「構造発見」 | 出力がないだけで、目的がないわけではない |
| 強化学習 | 環境との相互作用を通じて、報酬を最大化する行動を学習する手法 | 「エージェント・環境・状態・行動・報酬」 | 正解ラベルではなく報酬で学習する |
| 回帰問題 | 連続値を予測する問題 | 売上、価格、気温、株価など | ロジスティック回帰は名前に回帰があるが分類 |
| 分類問題 | 離散的なカテゴリを予測する問題 | 犬/猫、正常/異常、迷惑/通常 | 数値でもカテゴリなら分類になることがある |

### 2-2. 教師あり学習の代表手法

| 重要語句 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 線形回帰 | データに最も当てはまる直線・平面を使って連続値を予測する手法 | 回帰問題の基本 | 分類問題には基本的に使わない |
| 単回帰分析 | 1種類の入力から連続値を予測する回帰分析 | 入力が1つ | 出力が1つという意味ではない |
| 重回帰分析 | 複数種類の入力から連続値を予測する回帰分析 | 入力が複数 | 複数の出力を予測するという意味ではない |
| ラッソ回帰 | 線形回帰に正則化を加えた手法の1つ | 正則化ありの回帰 | リッジ回帰とセットで出る |
| リッジ回帰 | 線形回帰に正則化を加えた手法の1つ | 正則化ありの回帰 | ラッソと細かい数式差まではG検定では深追いしすぎない |
| ロジスティック回帰 | 分類問題に用いる手法。シグモイド関数で確率を出す | 名前に「回帰」でも分類 | 回帰問題用と誤解しやすい |
| シグモイド関数 | 出力を0〜1に変換する関数 | 2クラス分類の確率出力 | 多クラス分類ではソフトマックス関数 |
| ソフトマックス関数 | 複数クラスの出力を確率分布にする関数 | 多クラス分類 | 2クラス分類はシグモイドが基本 |
| 決定木 | 特徴量の値に基づいて分岐し、予測結果を出すモデル | 木構造・分岐 | ランダムフォレストの部品 |
| ランダムフォレスト | 複数の決定木を作り、多数決などで予測する手法 | 決定木＋バギング＋アンサンブル | ブースティングと混同しやすい |
| ブートストラップサンプリング | データからランダムに一部を取り出して学習に使う方法 | ランダムフォレストで使う | 特徴量のランダム抽出とセットで押さえる |
| アンサンブル学習 | 複数モデルを組み合わせて性能を高める手法 | バギング、ブースティング | 1つのモデルだけを選ぶ手法ではない |
| バギング | 複数モデルを並列に学習させ、平均や多数決で統合する手法 | 並列・多数決 | ブースティングは直列 |
| ブースティング | 複数モデルを逐次的に学習し、誤りを補正していく手法 | 直列・誤認識を重視 | バギングより学習時間がかかりやすい |
| AdaBoost | 誤分類データの重みを大きくして次の弱識別器を学習する手法 | 誤ったデータを重視 | バギングではなくブースティング |
| 勾配ブースティング | 前モデルの予測誤差を小さくするように逐次学習する手法 | 誤差を関数として捉える | ランダムフォレストとは別 |
| XGBoost | 勾配ブースティングを高速化・高性能化した代表的アルゴリズム | 勾配ブースティング系 | ランダムフォレスト系ではない |
| SVM | クラス間のマージンを最大化する境界を求める分類手法 | マージン最大化 | ディープラーニング以前に人気が高かった手法 |
| マージン最大化 | 異なるクラスのデータ点との距離が最大になる境界を求める考え方 | SVMの核心 | 単に境界線を引くだけではない |
| カーネル関数 | データを高次元空間に写像する関数 | 非線形分類を可能にする | フーリエ関数ではない |
| カーネルトリック | 高次元写像の計算を効率よく扱うテクニック | SVMとセット | カーネル関数そのものと混同しない |
| 自己回帰モデル | 過去の時系列データから現在・将来を予測するモデル | 株価、人口、通信量など | 画像分類や迷惑メール分類ではない |
| VARモデル | 複数種類の時系列データを扱う自己回帰モデル | ベクトル自己回帰 | ARモデルの多変量版 |

### 2-3. 教師なし学習の代表手法

| 重要語句 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| クラスタリング | 似たデータをグループに分ける手法 | 正解ラベルなし | 分類とは違い、正解カテゴリは与えられない |
| クラスタ | クラスタリングで得られるグループ | グループのこと | クラス分類のクラスと混同注意 |
| k-means法 | あらかじめ決めたk個のクラスタにデータを分ける手法 | 重心を計算し、近い重心に割り当てる | kは自動で決まらず、基本的に人が設定する |
| 階層なしクラスタリング | 並列にクラスタへ分ける方法 | k-means法 | 階層構造は作らない |
| 階層ありクラスタリング | クラスタの階層構造を求める方法 | ウォード法、最短距離法 | デンドログラムとセット |
| ウォード法 | クラスタ内の平方和が小さくなるようにまとめる階層的クラスタリング | 階層あり | k-meansではない |
| 最短距離法 | 最も距離が近いデータ・クラスタ同士をまとめる手法 | 階層あり | デンドログラムを作る |
| デンドログラム | 階層的クラスタリングの結果を木構造で表した図 | 樹形図 | ヒストグラムやパレート図ではない |
| 主成分分析 | 相関のある多数の特徴量を、相関のない少数の特徴量へ変換する手法 | 次元削減 | クラスタリングではない |
| PCA | Principal Component Analysis。主成分分析 | 次元削減の代表 | 教師あり学習ではない |
| 特異値分解 | 次元削減の手法。文章データなどで使われる | SVD | PCAと関連するが別名ではない |
| MDS | 多次元尺度構成法。高次元データを2次元などに可視化する手法 | 可視化 | 分類手法ではない |
| t-SNE | 高次元データを2次元・3次元に可視化する手法 | 可視化で頻出 | 教師あり分類器ではない |
| 協調フィルタリング | 似たユーザーの行動をもとに推薦する手法 | レコメンド | コールドスタート問題がある |
| コールドスタート問題 | 参考データが少ないため推薦できない問題 | 協調フィルタリングの弱点 | コンテンツベースは回避しやすい |
| コンテンツベースフィルタリング | 商品側の特徴量を使って似た商品を推薦する手法 | 商品特徴ベース | 他ユーザー情報は使わない |
| トピックモデル | 文書が複数の潜在トピックから生成されると仮定するモデル | 文書分類・推薦 | 1文書1クラスタとは限らない |
| LDA | 潜在的ディリクレ配分法。代表的なトピックモデル | トピックモデルの代表 | 線形判別分析のLDAとは文脈注意 |

### 2-4. 強化学習の重要語句

| 重要語句 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| エージェント | 環境内で行動する主体 | 強化学習の主役 | 学習データそのものではない |
| 環境 | エージェントが行動する対象世界 | 状態と報酬を返す | 教師データではない |
| 状態 | 環境から得られる現在の情報 | 状態を見て行動する | 過去すべての履歴とは限らない |
| 行動 | エージェントが選択する操作 | 報酬に影響する | 分類ラベルではない |
| 報酬 | 行動の良し悪しを示すスコア | 最大化したいもの | 正解ラベルとは違う |
| 累積報酬 | 将来にわたって得られる報酬の合計 | 強化学習の目的 | 直近報酬だけではない |
| 割引率 | 将来の報酬をどれくらい重視するかを決める値 | discount rate | 学習率とは違う |
| 活用 | 既知情報から最も報酬が高そうな行動を選ぶこと | exploitation | 探索と対になる |
| 探索 | 未知のより良い行動を探すこと | exploration | 活用とトレードオフ |
| バンディットアルゴリズム | 活用と探索のバランスを取る手法 | ε-greedy、UCB | 強化学習の代表的考え方 |
| ε-greedy方策 | 基本は最良行動を選び、一定確率εでランダム行動を選ぶ方策 | 活用＋一定確率で探索 | 常にランダムではない |
| UCB方策 | 期待値が高い選択肢を選びつつ、試行回数が少ない行動も優先する方策 | 試していない選択肢を考慮 | ε-greedyとは判断基準が違う |
| 方策 | 状態から行動を選ぶ戦略 | policy | 価値関数とは別 |
| マルコフ性 | 未来の状態は現在の状態にのみ依存し、過去には依存しないという性質 | 「未来は現在にのみ依存」 | 「過去にも依存する」は誤り |
| マルコフ決定過程 | マルコフ性を仮定した強化学習のモデル化 | MDP | 強化学習の定式化で頻出 |
| 状態価値関数 | ある状態の価値を表す関数 | state-value function | 行動価値関数と区別 |
| 行動価値関数 | ある状態である行動をとる価値を表す関数 | action-value function | 単に価値関数といえばこれを指すことが多い |
| Q値 | 行動価値関数の値 | Q-learningとセット | 方策そのものではない |
| Q学習 | 行動価値関数を最適化する強化学習手法 | 価値関数ベース | 方策勾配法ではない |
| SARSA | Q学習と同じく行動価値関数を扱う手法 | 価値関数系 | Q学習との細かい差は深追いしすぎない |
| 方策勾配法 | 方策を直接パラメータ化して学習する手法 | policy gradient | 価値関数を直接最適化する手法ではない |
| REINFORCE | 方策勾配法ベースの代表手法 | AlphaGoにも関連 | Q学習ではない |
| Actor-Critic | 行動を決めるActorと、方策を評価するCriticを組み合わせる手法 | 方策勾配＋価値関数 | Q学習単体ではない |

### 2-5. モデル評価の重要語句

| 重要語句 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 訓練データ | モデルの学習に使うデータ | training data | 評価専用ではない |
| 検証データ | モデル調整に使うデータ | validation data | 最終評価には使わない |
| テストデータ | 最終的な性能評価に使うデータ | test data | 学習に使ってはいけない |
| ホールドアウト検証 | データを訓練データとテストデータに1回分割して評価する方法 | シンプルな分割 | データが少ないと評価がブレやすい |
| k-分割交差検証 | データをk個に分け、複数回学習・評価する方法 | データが少ないとき有効 | 学習時間は増えやすい |
| 平均二乗誤差 | 予測値と実測値の差を2乗して平均する評価指標 | MSE | 主に回帰で使う |
| RMSE | MSEの平方根 | 単位が元データに近くなる | MSEとは値のスケールが違う |
| MAE | 絶対値誤差の平均 | 外れ値の影響がMSEより小さめ | 二乗しない |
| 混同行列 | 予測と実際の組み合わせを表にしたもの | TP, FP, FN, TN | 評価指標の基礎 |
| 真陽性 | 正と予測し、実際も正 | TP | 正しく検出できた |
| 偽陽性 | 正と予測したが、実際は負 | FP | 誤検出。第一種過誤 |
| 偽陰性 | 負と予測したが、実際は正 | FN | 見逃し。第二種過誤 |
| 真陰性 | 負と予測し、実際も負 | TN | 正しく除外できた |
| 正解率 | 全体のうち正しく予測できた割合 | Accuracy | データ偏りに弱い |
| 適合率 | 正と予測したもののうち、本当に正だった割合 | Precision | 誤検出を減らしたいとき重視 |
| 再現率 | 実際に正であるもののうち、正と予測できた割合 | Recall | 見逃しを減らしたいとき重視 |
| F値 | 適合率と再現率の調和平均 | PrecisionとRecallのバランス | 正解率とは違う |
| ROC曲線 | 閾値を変えたときのFPRとTPRの関係を表す曲線 | 2クラス分類の評価 | TPRは再現率と同じ |
| AUC | ROC曲線の下側面積 | 1に近いほど性能が高い | 0.5付近はランダムに近い |
| 過学習 | 訓練データに最適化されすぎ、未知データで性能が落ちる状態 | overfitting | 訓練データ高精度＝良いとは限らない |
| オッカムの剃刀 | 必要以上に複雑な仮定を置くべきでないという考え方 | モデル複雑度の話 | 複雑なモデルが常に良いわけではない |
| AIC | 赤池情報量基準 | モデル選択の基準 | パラメータ数にペナルティ |
| BIC | ベイズ情報量基準 | モデル選択の基準 | データ数が大きいとペナルティ影響が大きい |

## 3. 重要論点の整理

### 3-1. 教師あり学習：回帰と分類をまず分ける

| 問題文の表現 | 判定 | 理由 |
|---|---|---|
| 将来の売上を予測したい | 回帰 | 売上は連続値 |
| 株価を予測したい | 回帰 | 時系列の連続値 |
| 画像が犬か猫かを判定したい | 分類 | カテゴリ判定 |
| 迷惑メールか通常メールかを判定したい | 分類 | 2クラス分類 |
| 顧客が解約するかしないかを予測したい | 分類 | Yes/No |
| 商品をおすすめしたい | 教師なし学習系の推薦 | 協調フィルタリングなど |

### 3-2. ロジスティック回帰は「分類」

試験でかなり狙われる。

| 手法 | 名前の印象 | 実際の用途 |
|---|---|---|
| 線形回帰 | 回帰っぽい | 回帰 |
| リッジ回帰 | 回帰っぽい | 回帰 |
| ラッソ回帰 | 回帰っぽい | 回帰 |
| ロジスティック回帰 | 回帰っぽい | 分類 |

ロジスティック回帰は、シグモイド関数で0〜1の確率を出し、閾値以上なら正例、未満なら負例と判断する。

### 3-3. 2クラス分類と多クラス分類

| 分類 | 出力関数 | 例 |
|---|---|---|
| 2クラス分類 | シグモイド関数 | 迷惑メール/通常メール、不良品/良品 |
| 多クラス分類 | ソフトマックス関数 | 犬/猫/鳥/馬、数字0〜9分類 |

引っかけ：
- 「多クラス分類にはシグモイド関数」→基本は誤り
- 「ロジスティック回帰は回帰問題に使う」→誤り

### 3-4. アンサンブル学習：バギングとブースティング

| 観点 | バギング | ブースティング |
|---|---|---|
| 学習の進め方 | 並列 | 直列・逐次 |
| 代表例 | ランダムフォレスト | AdaBoost、勾配ブースティング、XGBoost |
| 考え方 | 複数モデルの多数決・平均 | 前のモデルの誤りを次で補正 |
| 特徴 | 安定性を上げる | 精度が高くなりやすい |
| 注意点 | 個々のモデルをランダムに作る | 学習時間がかかりやすい |

### 3-5. ランダムフォレストの理解

ランダムフォレストは以下の組み合わせ。

| 要素 | 内容 |
|---|---|
| ベースモデル | 決定木 |
| 学習方法 | バギング |
| データ | ブートストラップサンプリングでランダム抽出 |
| 特徴量 | 各決定木で一部をランダム抽出 |
| 出力 | 複数決定木の多数決・平均 |
| 属するカテゴリ | アンサンブル学習 |

試験では「複数の決定木」「ランダム」「多数決」が出たらランダムフォレスト。

### 3-6. SVMの理解

| 用語 | 押さえ方 |
|---|---|
| SVM | 分類境界を求める手法 |
| マージン最大化 | クラス間の距離が最大になる境界を探す |
| カーネル関数 | データを高次元空間へ写像する |
| カーネルトリック | 高次元計算を効率的に行うテクニック |

試験での定番文：
「SVMでは、データを高次元空間に写像し、写像後の空間で線形分類を行えるようにする。その際に用いる関数をカーネル関数という。」

### 3-7. 教師なし学習：クラスタリングと次元削減

| 手法 | 何をするか | キーワード |
|---|---|---|
| k-means法 | k個のクラスタに分ける | 重心、距離、kを事前設定 |
| 階層的クラスタリング | クラスタの階層構造を作る | ウォード法、最短距離法、デンドログラム |
| 主成分分析 | 相関のある多数の特徴量を少数の無相関な特徴量に変換 | 次元削減 |
| 協調フィルタリング | 似たユーザーの行動から推薦 | レコメンド、コールドスタート問題 |
| トピックモデル | 文書を複数の潜在トピックに確率的に分類 | LDA |

### 3-8. 強化学習：報酬最大化

強化学習は「正解ラベルを当てる」のではなく、「行動して報酬を最大化する」。

| 概念 | 内容 |
|---|---|
| 目的 | 将来にわたる累積報酬を最大化する |
| 問題 | 活用と探索のバランス |
| 活用 | 今わかっている中で最も良い行動を選ぶ |
| 探索 | もっと良い行動があるか試す |
| 方策 | 状態から行動を選ぶ戦略 |
| 価値関数 | 状態や行動の価値を評価する関数 |
| Q学習 | 行動価値関数を最適化する手法 |
| 方策勾配法 | 方策そのものを直接学習する手法 |
| Actor-Critic | Actorが行動を決め、Criticが評価する |

### 3-9. 評価：データ分割が大事

| データ | 役割 |
|---|---|
| 訓練データ | モデルを学習させる |
| 検証データ | モデル調整・ハイパーパラメータ調整に使う |
| テストデータ | 最終評価に使う |

重要：
- テストデータで調整してはいけない
- 訓練データだけで高精度でも意味がない
- 未知データへの性能を見るのが目的

### 3-10. 評価指標の使い分け

| 指標 | 式のイメージ | 使う場面 |
|---|---|---|
| 正解率 | 全体のうち正解した割合 | クラスの偏りが少ないとき |
| 適合率 | 正と予測したもののうち本当に正だった割合 | 誤検出を減らしたいとき |
| 再現率 | 実際に正であるもののうち正と検出できた割合 | 見逃しを減らしたいとき |
| F値 | 適合率と再現率のバランス | 適合率・再現率を両方見たいとき |
| AUC | ROC曲線の下側面積 | 閾値に依存しない分類性能評価 |

### 3-11. 不良品検出で正解率だけ見るのは危険

例：
10,000個中、不良品が3個しかない場合、全部「良品」と予測しても正解率は99.97%。

でも、不良品は1個も見つけていない。

このような場合、正解率ではなく再現率やF値を見るべき。

## 4. 似た用語の違い

### 4-1. 教師あり学習・教師なし学習・強化学習

| 比較 | 教師あり学習 | 教師なし学習 | 強化学習 |
|---|---|---|---|
| 正解データ | ある | ない | ない。代わりに報酬がある |
| 目的 | 入力から出力を予測 | データ構造を発見 | 累積報酬を最大化 |
| 例 | 売上予測、画像分類 | 顧客分類、次元削減 | ゲームAI、自動運転、ロボット制御 |
| 試験キーワード | ラベル、回帰、分類 | クラスタ、構造、類似度 | エージェント、環境、報酬、方策 |

### 4-2. 回帰問題と分類問題

| 比較 | 回帰問題 | 分類問題 |
|---|---|---|
| 出力 | 連続値 | 離散値・カテゴリ |
| 例 | 売上、価格、体重、株価 | 犬/猫、不良品/良品、迷惑/通常 |
| 代表手法 | 線形回帰、自己回帰モデル | ロジスティック回帰、SVM |
| 評価 | MSE、RMSE、MAE | 正解率、適合率、再現率、F値、AUC |

### 4-3. ロジスティック回帰と線形回帰

| 比較 | 線形回帰 | ロジスティック回帰 |
|---|---|---|
| 用途 | 回帰問題 | 分類問題 |
| 出力 | 連続値 | 確率 |
| 関数 | 直線・平面で予測 | シグモイド関数 |
| 試験注意 | 回帰と素直に覚える | 名前に回帰でも分類 |

### 4-4. シグモイド関数とソフトマックス関数

| 比較 | シグモイド関数 | ソフトマックス関数 |
|---|---|---|
| 用途 | 2クラス分類 | 多クラス分類 |
| 出力 | 0〜1の値 | 各クラスの確率分布 |
| 合計 | 1とは限らない場合がある | 各クラス確率の合計が1 |
| 例 | 迷惑メールかどうか | 犬・猫・鳥のどれか |

### 4-5. バギングとブースティング

| 比較 | バギング | ブースティング |
|---|---|---|
| モデル作成 | 並列 | 逐次 |
| 代表手法 | ランダムフォレスト | AdaBoost、XGBoost |
| 統合方法 | 多数決・平均 | 弱識別器を統合 |
| 着眼点 | 分散を下げて安定化 | 誤りを補正して精度向上 |
| 試験キーワード | ブートストラップ、ランダム、決定木 | 誤認識、重み、弱識別器、強識別器 |

### 4-6. k-means法と階層的クラスタリング

| 比較 | k-means法 | 階層的クラスタリング |
|---|---|---|
| クラスタ数 | kを事前に決める | 木構造を見て決められる |
| 構造 | 階層なし | 階層あり |
| 代表語 | 重心、距離、再割り当て | ウォード法、最短距離法 |
| 結果の表現 | k個のクラスタ | デンドログラム |

### 4-7. 協調フィルタリングとコンテンツベースフィルタリング

| 比較 | 協調フィルタリング | コンテンツベースフィルタリング |
|---|---|---|
| 使う情報 | 他ユーザーの購買・評価履歴 | 商品の特徴量 |
| 推薦の考え方 | 似たユーザーが買ったものを推薦 | 似た特徴の商品を推薦 |
| 弱点 | コールドスタート問題 | 他ユーザーの傾向を使えない |
| 試験キーワード | 購買履歴、似たユーザー | 商品特徴、対象ユーザーのデータ |

### 4-8. 適合率と再現率

| 比較 | 適合率 | 再現率 |
|---|---|---|
| 見ているもの | 予測した正例の正しさ | 実際の正例を拾えた割合 |
| 式 | TP / (TP + FP) | TP / (TP + FN) |
| 重視する場面 | 誤検出を減らしたい | 見逃しを減らしたい |
| 例 | 迷惑メール判定で通常メールを迷惑扱いしたくない | がん検査で患者を見逃したくない |

### 4-9. 過学習と汎化性能

| 用語 | 意味 |
|---|---|
| 過学習 | 訓練データに合わせすぎて、未知データに弱くなる状態 |
| 汎化性能 | 未知データに対しても正しく予測できる性能 |
| 対策 | データ分割、交差検証、正則化、モデル複雑度の調整 |

## 5. 試験で狙われる引っかけ

### 5-1. 「ロジスティック回帰＝回帰問題」は誤り

| 選択肢例 | 判定 |
|---|---|
| ロジスティック回帰は回帰問題に用いられる | 誤り |
| ロジスティック回帰は分類問題に用いられる | 正しい |
| 多クラス分類にはソフトマックス関数が用いられる | 正しい |
| 2クラス分類ではシグモイド関数が用いられる | 正しい |

### 5-2. 「バギング」と「ブースティング」の混同

| 引っかけ文 | どこが危険か |
|---|---|
| バギングは前のモデルの誤りを次のモデルで補正する | これはブースティング |
| ブースティングは複数モデルを並列に学習する | これはバギング |
| ランダムフォレストはブースティングの代表例 | 誤り。バギング系 |
| AdaBoostはバギングの代表例 | 誤り。ブースティング系 |

### 5-3. 「k-means法はクラスタ数を自動で決める」は誤り

k-means法のkは、基本的に事前に指定する。
問題文に「あらかじめ決められた数のクラスタ」「重心」「最も近いクラスタ」が出たらk-means法。

### 5-4. 「主成分分析＝クラスタリング」は誤り

| 手法 | 目的 |
|---|---|
| k-means法 | グループ分け |
| 主成分分析 | 次元削減 |
| 協調フィルタリング | 推薦 |
| トピックモデル | 文書の潜在トピック推定 |

### 5-5. 正解率だけでモデルを評価してはいけない

データに偏りがある場合、正解率は高く見えても実用上ダメなモデルがある。

例：
- 不良品がほとんどない
- 病気の人が少ない
- 不正取引が少ない

この場合は、再現率・適合率・F値を確認する。

### 5-6. TP, FP, FN, TNの混同

| 用語 | 覚え方 |
|---|---|
| TP | 正と予測して、本当に正 |
| FP | 正と予測したが、本当は負 |
| FN | 負と予測したが、本当は正 |
| TN | 負と予測して、本当に負 |

特に重要：
- 偽陽性 FP = 誤検出
- 偽陰性 FN = 見逃し

### 5-7. マルコフ性の定番引っかけ

正しい表現：
「未来の状態は、現在の状態にのみ依存し、過去の状態には依存しない。」

誤答例：
- 未来の状態は過去と現在の両方に依存する
- 未来の状態は過去の状態にのみ依存する
- 未来の状態は何にも依存しない

### 5-8. Q学習の引っかけ

| 選択肢 | 判定 |
|---|---|
| Q学習は行動価値関数を最適化する | 正しい |
| Q学習は方策勾配法ベースである | 誤り |
| Q学習はActorとCriticを用いる | 誤り。これはActor-Critic |
| Q学習は方策オン型である | テキスト上は誤り。方策オフ型として押さえる |

### 5-9. AUCの引っかけ

| 表現 | 判定 |
|---|---|
| AUCはROC曲線の下側面積である | 正しい |
| AUCは1に近いほど性能が高い | 正しい |
| ROC曲線は横軸TPR、縦軸FPRである | 誤り。横軸FPR、縦軸TPR |
| TPRは再現率と同じ | 正しい |

## 10. 最短復習用まとめ

### 10-1. 30秒復習

- 教師あり学習：正解ラベルあり。回帰と分類。
- 教師なし学習：正解ラベルなし。クラスタリング、次元削減、推薦。
- 強化学習：報酬を最大化する行動を学習。
- 回帰は連続値、分類はカテゴリ。
- ロジスティック回帰は分類。
- 多クラス分類はソフトマックス関数。
- ランダムフォレストは複数の決定木を使うバギング系アンサンブル。
- ブースティングは誤りを補正しながら逐次学習。
- SVMはマージン最大化。カーネル関数で高次元へ写像。
- k-means法は重心を使ってk個にクラスタリング。
- PCAは次元削減。
- 協調フィルタリングは似たユーザーから推薦。コールドスタート問題あり。
- Q学習は行動価値関数を最適化。
- マルコフ性は「未来は現在の状態にのみ依存」。
- 正解率だけでなく、適合率・再現率・F値を見る。
- AUCは1に近いほど性能が高い。
- 過学習は訓練データに合わせすぎて未知データに弱いこと。

### 10-3. 玲奈メモ

第3章は、難しく見えるけど、試験ではかなりパターン化されている。
数式を深追いするより、まずは「手法名 → 何をする → 何と間違えやすいか」を固めるのが正解。

特にとくとくんは、ここを実務接続するとかなり強い。
AI導入やDX推進では、モデルを作れること以上に「これは分類問題なのか、回帰問題なのか」「正解率だけ見ていいのか」「見逃しリスクはどれくらいか」を判断できる人が価値を持つ。

まずは章末問題レベルで、以下を即答できるようにする。

- ロジスティック回帰＝分類
- ランダムフォレスト＝決定木＋バギング
- ブースティング＝逐次学習＋誤り補正
- SVM＝マージン最大化＋カーネル関数
- k-means＝重心＋k個のクラスタ
- PCA＝次元削減
- 協調フィルタリング＝推薦＋コールドスタート問題
- Q学習＝行動価値関数
- マルコフ性＝未来は現在にのみ依存
- 再現率＝見逃しを減らす
- 適合率＝誤検出を減らす
