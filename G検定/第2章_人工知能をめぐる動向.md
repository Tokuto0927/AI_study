## 0. この章のゴール

第2章のゴールは、AI研究の歴史的な流れを「技術の考え方」とセットで理解すること。

G検定では、第2章は単なる歴史暗記ではなく、次のような形で問われやすい。

| 問われ方 | 例 |
|---|---|
| 用語の意味 | 幅優先探索、深さ優先探索、オントロジー、特徴量、LLMとは何か |
| 似た用語の区別 | Mini-Max法とαβ法、意味ネットワークとオントロジー、機械学習とディープラーニング |
| 歴史上の位置づけ | 第1次AIブーム、第2次AIブーム、第3次AIブームで中心だった技術 |
| ひっかけ | Watsonは意味を理解しているわけではない、SuperVisionはチーム名でAlexNetはモデル名 |
| 実用上の限界 | 探索の組み合わせ爆発、知識獲得のボトルネック、特徴量設計の難しさ |

この章は「AIがどう賢くなってきたか」を3段階で押さえる。

| 時代 | 中心テーマ | キーワード |
|---|---|---|
| 第1次AIブーム | 探索・推論 | 探索木、幅優先探索、深さ優先探索、Mini-Max法、αβ法、モンテカルロ法 |
| 第2次AIブーム | 知識表現 | エキスパートシステム、MYCIN、意味ネットワーク、オントロジー、Cyc、Watson |
| 第3次AIブーム以降 | 機械学習・深層学習 | ビッグデータ、特徴量、特徴表現学習、ディープラーニング、ILSVRC、LLM、Transformer |

| 段階 | AIの考え方 | 強み | 限界 |
|---|---|---|---|

## 2. 重要用語・概念

## 2-1. 探索・推論

| 用語 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 探索木 | 問題を枝分かれする木構造で表したもの | 迷路やハノイの塔などをコンピュータで扱うための表現 | 「検索木」と混同しない |
| ノード | 探索木の各要素 | 分岐点・状態・局面などを表す | 木の枝そのものではない |
| 幅優先探索 | スタートに近いノードから順に探索する方法 | 最短経路を必ず見つけるが、メモリを多く使う | 「メモリが少なくて済む」は誤り |
| 深さ優先探索 | 進めるところまで進み、行き止まりなら戻る方法 | メモリは少なくて済むが、最短経路とは限らない | 「必ず最短」は誤り |
| ハノイの塔 | 探索木で解ける代表的なパズル | 状態を記号化して探索する例 | 複雑な現実問題ではなく、ルールが明確な問題 |
| プランニング | 目標達成のための行動計画を立てる技術 | ロボット行動計画で登場 | 単なる検索ではなく、前提条件・行動・結果を扱う |
| STRIPS | 前提条件・行動・結果で行動計画を記述する手法 | 「プランニング＝STRIPS」とセットで覚える | SHRDLUと混同しない |
| SHRDLU | 積み木の世界で自然言語の指示を受けて行動できたシステム | 限定世界でのプランニング・自然言語処理の代表例 | 汎用AIではない |
| コスト | 探索における評価値・費用・不利さ | 探索を効率化するために使う | 「費用」だけでなく、時間や不利さも含む |
| ヒューリスティックな知識 | 経験的・発見的に探索を効率化する知識 | 全探索できないときに使う | 必ず正解を保証する知識ではない |
| Mini-Max法 | 自分はスコア最大、相手はスコア最小を選ぶと仮定して戦略を決める方法 | ボードゲーム戦略の基本 | ランダムに試す方法ではない |
| αβ法 | Mini-Max法の無駄な探索を枝刈りする方法 | Mini-Max法を効率化する手法 | Mini-Max法そのものと混同しない |
| αカット | 自分の局面で、探索不要な相手側の枝を切ること | α値は自分側の最大候補 | βカットと逆にしやすい |
| βカット | 相手の局面で、探索不要な自分側の枝を切ること | β値は相手側の最小候補 | αカットと逆にしやすい |
| モンテカルロ法 | ランダムに試行を繰り返し、勝率などから良い手を評価する方法 | 囲碁などで有効になった探索評価法 | ブルートフォースではない |
| プレイアウト | ランダムにゲームを終局まで進めること | モンテカルロ法とセット | 探索アルゴリズム名ではなく、終局まで進める行為 |
| ブルートフォース | 全パターンを力任せに探索する方法 | 探索空間が小さいときは可能 | 探索空間が巨大な場合には現実的でない |
| AlphaGo | DeepMindの囲碁AI | 2016年、世界トップ級棋士に勝利 | 単なる全探索や従来型モンテカルロだけで勝ったわけではない |

## 2-2. 知識表現

| 用語 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 人工無脳 | 内容を理解せず、ルールに従って会話するプログラム | チャットボットの原型として登場 | 本当に意味理解しているわけではない |
| ELIZA | ワイゼンバウムが開発した初期の対話プログラム | 人工無脳の代表例 | 過去ログから自律学習したわけではない |
| イライザ効果 | 機械的応答に知性があるように感じる心理効果 | 「理解していないのに理解しているように感じる」 | チューリングテストそのものではない |
| エキスパートシステム | 専門家の知識を取り込んだAIシステム | 第2次AIブームの中心 | データから自動学習する機械学習とは違う |
| MYCIN | 血液中のバクテリア診断支援を行うルールベースシステム | 「感染症・抗生物質・if-thenルール」とセット | ELIZAやWatsonと混同しない |
| DENDRAL | 未知の有機化合物を特定するエキスパートシステム | 知識工学につながる代表例 | 医療診断ではない |
| 知識工学 | 知識を扱うAIシステムを設計・構築する分野 | ファイゲンバウムと関連 | 機械学習そのものではない |
| 知識獲得のボトルネック | 人間の知識を取り出し、コンピュータに入れることが難しい問題 | 第2次AIブーム失速の重要理由 | 計算速度やメモリ不足だけの問題ではない |
| 意味ネットワーク | 概念をノード、関係をリンクで表す知識表現 | is-a、part-ofが頻出 | オントロジーと混同しやすい |
| is-a関係 | 「〜である」の関係。上位概念と下位概念を表す | 推移律が成立する | part-ofと混同しない |
| part-of関係 | 「〜の一部である」の関係 | 推移律が常に成立するわけではない | 「必ず推移律成立」は誤り |
| 継承 | 下位概念が上位概念の属性を引き継ぐこと | is-a関係とセット | part-ofの説明に使うと誤りになりやすい |
| オントロジー | 概念・語彙・関係を共有可能な形で明示的に定義する枠組み | 「概念化の明示的な仕様」 | 単なるデータベースではない |
| Cycプロジェクト | 一般常識をコンピュータに取り込もうとするプロジェクト | 1984年開始、現在も継続中 | 「2014年に終了」は誤り |
| ヘビーウェイトオントロジー | 哲学的・厳密に概念体系を構築する方法 | 正確だが時間とコストがかかる | 自動抽出向きではない |
| ライトウェイトオントロジー | 完全性より実用性重視で関係を構築する方法 | Webマイニング・データマイニングと相性が良い | 厳密な哲学的検討を重視するわけではない |
| セマンティックWeb | Webの意味をコンピュータに理解・処理させる技術 | オントロジーの応用 | 普通のWebページ閲覧とは違う |
| LOD | Linked Open Data。構造化データをリンクして公開・共有する技術 | コンピュータが処理しやすいデータのWeb | 単なるPDF公開ではない |
| Watson | IBMの質問応答システム | Jeopardy!で人間チャンピオンに勝利 | 意味を本当に理解しているわけではない |
| 東ロボくん | 東大合格を目指したAIプロジェクト | 図理解や古文・漢文データ不足などの限界があった | 東大に合格したわけではない |

## 2-3. 機械学習・深層学習

| 用語 | 意味 | 試験での押さえ方 | 間違えやすい点 |
|---|---|---|---|
| 機械学習 | プログラムがデータからパターンを学習する仕組み | データ量が多いほど望ましい結果を得やすい | ルールを人間が全部書く方式ではない |
| ビッグデータ | インターネット普及などで利用可能になった大量データ | 第3次AIブームの要因 | 明確な容量基準があるわけではない |
| 統計的自然言語処理 | 大量のコーパスから確率的に言語処理を行う方法 | bankの訳語選択などで説明される | 文法・意味を完全理解しているわけではない |
| コーパス | 言語処理に使う大量の文章・対訳データ | 統計的機械翻訳とセット | 単なる辞書ではない |
| 特徴量 | 注目すべきデータの特徴を数値などで表したもの | 機械学習の性能を左右する | 何でも特徴量にすればよいわけではない |
| 特徴量設計 | 人間が有効な特徴量を選ぶこと | 従来型機械学習で重要 | ディープラーニングでは特徴抽出も自動化される |
| 次元の呪い | 特徴が増えるほど必要データ量が急増する問題 | 次元が増えるほど学習が難しくなる | 特徴量は多ければ多いほど良い、は誤り |
| 特徴表現学習 | 機械学習自身が特徴量を発見するアプローチ | ディープラーニングの核心 | 人間が特徴量を全部設計するわけではない |
| ディープラーニング | 多層ニューラルネットワークで特徴を自動学習する手法 | 特徴表現学習を行う機械学習の一種 | 機械学習とは別物ではなく、機械学習の一種 |
| ブラックボックス | 判断理由が人間に分かりにくい性質 | DLの弱点として問われる | 全ての機械学習がブラックボックスとは限らない |
| ニューラルネットワーク | 生物の神経回路を模した学習モデル | 機械学習の一種 | ディープラーニングと完全同義ではない |
| 形式ニューロン | 初期の単純化されたニューロンモデル | マカロックとピッツ | 学習できるモデルではなかった |
| パーセプトロン | ローゼンブラットが提案した学習可能なニューロンモデル | 直線分離可能な問題を解ける | 直線分離不能な問題は苦手 |
| パーセプトロンの限界 | 直線で分けられない分類問題に対応できないこと | ミンスキーらが指摘 | ニューラルネットワーク研究の停滞につながった |
| 多層パーセプトロン | パーセプトロンを階層的につないだモデル | 限界克服に重要 | 学習法なしでは活用が難しかった |
| 誤差逆伝播法 | 多層ネットワークを学習させる手法 | ラメルハートら、1986年 | 単層パーセプトロンの話ではない |
| LeNet | ヤン・ルカンによるCNNの基礎的モデル | 画像認識ニューラルネットワークの基礎 | AlexNetと混同しない |
| SVM | サポートベクターマシン | 1990年代に人気を集めた機械学習手法 | ディープラーニングそのものではない |
| オートエンコーダ | 入力と同じものを出力するよう学習するモデル | 深いネットワーク学習の足場の1つ | LLMとは別物 |
| ILSVRC | 画像認識精度を競う競技会 | 2012年にDLが圧勝 | 自然言語処理コンテストではない |
| SuperVision | 2012年ILSVRCで圧勝したチーム名 | チーム名 | モデル名はAlexNet |
| AlexNet | 2012年ILSVRCで注目されたニューラルネットワークモデル | DLブームの象徴 | SuperVisionと混同しない |
| 生成AI | 確率的に次の単語などを選び、文章・画像などを生成するAI | ChatGPTで社会的に浸透 | 検索結果をそのまま返すだけではない |
| Transformer | 2017年の論文で提案された言語処理に強い構造 | LLMを支える重要技術 | Attentionと完全同義ではない |
| Attention | 単語同士の関係性に注目する仕組み | Transformerの重要要素 | 「注意力」という一般語だけで理解しない |
| LLM | 大量の文章を学習する大規模言語モデル | GPTなどの基盤 | 事前学習だけで理想的な応答になるわけではない |
| 事前学習 | 大量データから一般的な言語構造を学ぶこと | プリトレーニング | ファインチューニングと混同しない |
| ファインチューニング | 特定用途や望ましい応答に合わせて追加学習すること | LLMの応答品質向上に重要 | 事前学習そのものではない |
| パラメータ | 学習により調整される重みなど | LLMの規模比較で使う | パラメータ数だけで性能が決まるわけではない |

## 3. 重要論点の整理

## 3-1. 探索木・幅優先探索・深さ優先探索

| 観点 | 幅優先探索 | 深さ優先探索 |
|---|---|---|
| 探索の進め方 | スタートに近いノードから順に調べる | 行けるところまで深く進み、ダメなら戻る |
| 最短経路 | 必ず見つける | 保証されない |
| メモリ使用量 | 多い | 少ない |
| 失敗時 | 探索済みノードを保持する必要がある | 1つ手前に戻ればよい |
| 試験での合図 | 「最短距離」「メモリ不足」 | 「メモリ少」「最短とは限らない」 |

押さえ方：

- 幅優先探索：広く見る。最短に強い。メモリに弱い。
- 深さ優先探索：深く行く。メモリに強い。最短に弱い。

## 3-2. ボードゲームと探索の限界

ボードゲームでは、盤面の組み合わせが非常に多くなるため、すべてを探索することは現実的ではない。

| ゲーム | 組み合わせの多さ | 覚え方 |
|---|---:|---|
| オセロ | 約10の60乗 | 最小 |
| チェス | 約10の120乗 | オセロより大きい |
| 将棋 | 約10の220乗 | 持ち駒が使えるため複雑 |
| 囲碁 | 約10の360乗 | 最大 |

試験用の順番：

オセロ ＜ チェス ＜ 将棋 ＜ 囲碁

## 3-3. Mini-Max法・αβ法・モンテカルロ法

| 手法 | 何をするか | 試験でのキーワード | 注意点 |
|---|---|---|---|
| Mini-Max法 | 自分は最大、相手は最小を選ぶと仮定し、未来から逆算する | 最大・最小・ゲーム戦略 | ランダムではない |
| αβ法 | Mini-Max法で不要な探索を枝刈りする | αカット、βカット、枝刈り | Mini-Max法を効率化する手法 |
| モンテカルロ法 | ランダムな試行を何度も行い、勝率で評価する | プレイアウト、ランダム、勝率 | ブルートフォースではない |
| ブルートフォース | 全パターンを力任せに調べる | 全探索、力任せ | 囲碁のような巨大空間では不向き |

ポイント：

- Mini-Max法：理詰めで読む。
- αβ法：読まなくてよい枝を切る。
- モンテカルロ法：たくさんランダムに試す。
- ブルートフォース：全部試す。

## 3-4. エキスパートシステムと知識獲得のボトルネック

第2次AIブームでは、「人間の知識をコンピュータに入れれば賢くなる」と考えられた。

| 項目 | 内容 |
|---|---|
| 代表例 | MYCIN、DENDRAL |
| 技術 | if-thenルール、知識ベース |
| 強み | 専門分野では専門家のように振る舞える |
| 限界 | 専門家の暗黙知や一般常識を取り出すのが難しい |
| 失速理由 | 知識獲得のボトルネック、保守の困難さ |

試験では「知識獲得のボトルネック＝人間の知識を引き出してコンピュータに載せることが難しい」と覚える。

## 3-5. 意味ネットワークとオントロジー

| 項目 | 意味ネットワーク | オントロジー |
|---|---|---|
| 目的 | 概念と概念の関係をネットワークで表す | 知識を共有・再利用できるよう、語彙や関係を明示的に定義する |
| 表現 | ノードとリンク | 概念体系・仕様 |
| 代表関係 | is-a、part-of | is-a、part-ofなどを厳密に扱う |
| 強み | 直感的で分かりやすい | 複数人・複数システムで知識を共有しやすい |
| 注意点 | 記述ルールがバラバラになりやすい | 構築にコストがかかる場合がある |

## 3-6. is-a と part-of

| 関係 | 意味 | 推移律 | 例 |
|---|---|---|---|
| is-a | 〜である | 必ず成立する | 人間 is-a 哺乳類、哺乳類 is-a 動物 → 人間 is-a 動物 |
| part-of | 〜の一部である | 常に成立するとは限らない | 指 part-of 太郎、太郎 part-of 野球部 → 指 part-of 野球部 は成立しない |

ひっかけ：

- is-aは継承関係。
- part-ofは全体・部分関係。
- part-ofは推移律が必ず成立するとは限らない。

## 3-7. ヘビーウェイトオントロジーとライトウェイトオントロジー

| 観点 | ヘビーウェイトオントロジー | ライトウェイトオントロジー |
|---|---|---|
| 方針 | 厳密に概念体系を考える | 完全でなくても使える関係を作る |
| 人間の関与 | 大きい | 小さめ、自動化と相性が良い |
| コスト | 高い | 比較的低い |
| 相性 | 哲学的・厳密な知識体系 | Webマイニング、データマイニング |
| 代表例 | Cycプロジェクト | Watsonのライトウェイト・オントロジー |

## 3-8. 機械学習と特徴量

機械学習では、データに潜むパターンを学習する。

| 概念 | 内容 |
|---|---|
| サンプルデータ | 学習に使う事例 |
| 特徴量 | 注目すべき特徴を数値などで表したもの |
| 特徴量設計 | 人間が特徴量を選ぶこと |
| 特徴表現学習 | 機械が特徴量を自動で見つけること |
| 次元の呪い | 特徴量が増えるほど必要データ量が急増する問題 |

重要：

- 従来の機械学習では、人間の特徴量設計が性能を左右した。
- ディープラーニングでは、特徴量の抽出も自動で行う。
- ただし、抽出された特徴量の意味は人間に分かりにくく、ブラックボックス性がある。

## 3-9. ディープラーニングの歴史

| 年代 | 出来事 | 試験での押さえ方 |
|---|---|---|
| 1943年 | マカロックとピッツの形式ニューロン | 初期のニューロンモデル |
| 1958年 | ローゼンブラットのパーセプトロン | 学習可能なモデル |
| 1969年 | ミンスキーらがパーセプトロンの限界を指摘 | 第1次NNブームの停滞 |
| 1986年 | ラメルハートらが誤差逆伝播法を提案 | 多層ネットワーク学習の鍵 |
| 1989年 | ルカンのLeNet | CNNの基礎 |
| 1990年代 | SVMが人気 | NNブームが一時停滞 |
| 2006年頃 | ヒントンらが深層学習研究を牽引 | 第3次NNブームへ |
| 2012年 | ILSVRCでSuperVisionが圧勝 | AlexNet、DLブームの象徴 |
| 2015年 | 画像認識で人間の誤認識率を下回る | DLの実力を示す |
| 2022年 | ChatGPT公開 | 生成AI・LLMの社会的普及 |

## 3-10. LLMとTransformer

| 用語 | 内容 |
|---|---|
| Transformer | 文章中の単語の位置と単語同士の関係性を広範囲に学習できる技術 |
| Attention | どの単語がどの単語と関係しているかを重み付けする仕組み |
| LLM | 大量の文章を学習する大規模なニューラルネットワーク |
| 事前学習 | 大量テキストから一般的な言語構造を学ぶ |
| ファインチューニング | 特定用途や望ましい応答に合わせて追加学習する |
| パラメータ | 学習で調整される重み。モデル規模の指標になる |

ひっかけ：

- LLMは事前学習だけでは望ましい回答を出せるとは限らない。
- パラメータ数を増やせば必ず性能向上するわけではない。
- データ量と計算リソースも重要。
- TransformerはAttentionを使うが、Attentionそのものと完全同義ではない。

## 4. 似た用語の違い

## 4-1. 幅優先探索 vs 深さ優先探索

| 比較 | 幅優先探索 | 深さ優先探索 |
|---|---|---|
| 探し方 | 近い順に広く探索 | 先に深く探索 |
| 最短経路 | 保証あり | 保証なし |
| メモリ | 多く必要 | 少なくて済む |
| 試験のひっかけ | 「メモリが少ない」は誤り | 「最短を必ず見つける」は誤り |

## 4-2. Mini-Max法 vs αβ法 vs モンテカルロ法

| 比較 | Mini-Max法 | αβ法 | モンテカルロ法 |
|---|---|---|---|
| 基本思想 | 自分最大、相手最小で読む | Mini-Maxの無駄を削る | ランダム試行で勝率評価 |
| 使いどころ | ボードゲーム戦略 | Mini-Maxの高速化 | 囲碁など評価が難しいゲーム |
| キーワード | 最大・最小 | 枝刈り、αカット、βカット | プレイアウト、勝率、ランダム |
| 誤答パターン | ランダムと混同 | Mini-Maxそのものと混同 | ブルートフォースと混同 |

## 4-3. モンテカルロ法 vs ブルートフォース

| 比較 | モンテカルロ法 | ブルートフォース |
|---|---|---|
| やること | 一部をランダムに試す | 全部試す |
| 強み | 全探索不能な場合でも使える | 全部試せるなら確実 |
| 弱み | 結果は試行回数やランダム性に依存 | 組み合わせ爆発に弱い |
| 試験での見分け | プレイアウト、勝率 | 力任せ、全パターン |

## 4-4. 意味ネットワーク vs オントロジー

| 比較 | 意味ネットワーク | オントロジー |
|---|---|---|
| 主目的 | 概念間の関係を表す | 知識を共有・再利用できる仕様を作る |
| 形式 | ノードとリンク | 概念体系 |
| 代表語 | is-a、part-of | 概念化の明示的な仕様 |
| 弱点 | 人によって記述がバラバラになりやすい | 構築に手間がかかる |

## 4-5. is-a vs part-of

| 比較 | is-a | part-of |
|---|---|---|
| 意味 | 〜である | 〜の一部である |
| 関係 | 上位・下位 | 全体・部分 |
| 推移律 | 成立する | 成立するとは限らない |
| 例 | 人間 is-a 哺乳類 | 指 part-of 太郎 |

## 4-6. ヘビーウェイトオントロジー vs ライトウェイトオントロジー

| 比較 | ヘビーウェイト | ライトウェイト |
|---|---|---|
| 正確性 | 高く追求 | ほどほどでも実用重視 |
| 作り方 | 人間が厳密に考える | 自動抽出と相性が良い |
| コスト | 高い | 低め |
| 関連 | Cyc | Webマイニング、データマイニング、Watson |

## 4-7. エキスパートシステム vs 機械学習

| 比較 | エキスパートシステム | 機械学習 |
|---|---|---|
| 知識の入れ方 | 人間が専門知識をルール化 | データからパターンを学習 |
| 代表例 | MYCIN、DENDRAL | スパムフィルタ、レコメンド |
| 強み | 理由やルールが明確 | 大量データから高精度化 |
| 弱み | 知識獲得・保守が大変 | データ品質・特徴量に依存 |

## 4-8. 機械学習 vs ニューラルネットワーク vs ディープラーニング

| 比較 | 機械学習 | ニューラルネットワーク | ディープラーニング |
|---|---|---|---|
| 範囲 | データから学ぶ手法全般 | 生物の神経回路を模したモデル | 多層ニューラルネットワーク |
| 関係 | 一番広い | 機械学習の一種 | ニューラルネットワークの一種 |
| 例 | 決定木、SVM、k平均法 | パーセプトロン、多層パーセプトロン | CNN、RNN、Transformerなど |
| 試験ポイント | DLは機械学習の一部 | NNはDLと完全同義ではない | 特徴表現学習が重要 |

## 4-9. 特徴量設計 vs 特徴表現学習

| 比較 | 特徴量設計 | 特徴表現学習 |
|---|---|---|
| 誰が特徴を見つけるか | 人間 | 機械 |
| 代表 | 従来型機械学習 | ディープラーニング |
| 強み | 解釈しやすい | 複雑な特徴を自動で抽出できる |
| 弱み | 職人芸になりやすい | ブラックボックス化しやすい |

## 4-10. 事前学習 vs ファインチューニング

| 比較 | 事前学習 | ファインチューニング |
|---|---|---|
| 目的 | 一般的な言語構造を学ぶ | 特定タスクや望ましい応答に合わせる |
| データ | 大量の一般テキスト | 目的に応じたデータ |
| 試験での合図 | プリトレーニング、大量文章 | 微調整、特定用途 |
| ひっかけ | 事前学習だけで十分ではない | Transformerそのものではない |

## 5. 試験で狙われる引っかけ

| 引っかけ文 | 正誤 | 理由 |
|---|---:|---|
| 幅優先探索はメモリ使用量が少ない | 誤 | 幅優先探索は探索途中のノードを多く保持するためメモリを使う |
| 深さ優先探索は必ず最短経路を見つける | 誤 | 深く進むため、最短とは限らない |
| 探索木は検索エンジンの検索に使う木である | 誤 | 場合分けを木構造で表すもの |
| ボードゲームの組み合わせは、囲碁より将棋の方が多い | 誤 | オセロ ＜ チェス ＜ 将棋 ＜ 囲碁 |
| モンテカルロ法は全パターンを力任せに調べる | 誤 | 全探索ではなく、ランダム試行を繰り返す |
| ブルートフォース法はランダムにプレイアウトする方法 | 誤 | それはモンテカルロ法の説明 |
| αβ法はMini-Max法とは無関係な手法である | 誤 | Mini-Max法の探索を効率化する枝刈り手法 |
| STRIPSは前提条件・行動・結果で記述する | 正 | プランニングの代表手法 |
| SHRDLUは汎用的な自然言語理解AIである | 誤 | 積み木の世界という限定領域で動くシステム |
| ELIZAは過去の会話ログから自律的に学習した | 誤 | パターンに基づく機械的応答 |
| ELIZAは人間の発言を理解している | 誤 | 理解していないが、理解しているように感じる |
| MYCINは血液中のバクテリア診断支援を行う | 正 | if-thenルールによるエキスパートシステム |
| DENDRALは医療診断システムである | 誤 | 未知の有機化合物を特定するシステム |
| 知識獲得のボトルネックはコンピュータの記憶容量不足だけを指す | 誤 | 人間の知識を引き出し、形式化し、保守する難しさ |
| is-a関係では推移律が成立する | 正 | 人間 is-a 哺乳類、哺乳類 is-a 動物 → 人間 is-a 動物 |
| part-of関係では推移律が必ず成立する | 誤 | 文脈によって成立しない場合がある |
| Cycプロジェクトはすでに終了した | 誤 | 現在も継続中とされる |
| Webマイニングはヘビーウェイトオントロジーと相性が良い | 誤 | ライトウェイトオントロジーと相性が良い |
| Watsonは質問の意味を完全に理解して解答した | 誤 | 候補を検索・評価して選んでいる |
| ビッグデータには明確な容量基準がある | 誤 | 具体的な固定基準はない |
| ビッグデータは構造化データだけを指す | 誤 | 非構造化データも含まれる |
| レコメンドやスパムフィルタはビッグデータなしで実用化した | 誤 | 膨大なデータを利用した機械学習で実用化 |
| SuperVisionはモデル名である | 誤 | チーム名。モデル名はAlexNet |
| AlexNetは2012年ILSVRCで注目された | 正 | ディープラーニング注目の契機 |
| LLMはパラメータ数を増やせばデータ量に関係なく性能向上する | 誤 | データ量・計算リソースも必要 |
| 事前学習だけで望ましい回答を生成できる | 誤 | ファインチューニングなどの調整が必要 |
| Transformerは単語の位置や単語同士の関係性を考慮する | 正 | Attentionにより広範囲の関係を学習する |

## 7. 実務接続メモ

G検定では試験用に覚えるだけでよい部分もあるが、とくとくんのSE実務・将来のITコンサル/PM/AI活用人材視点では、次のように接続できる。

| 学習内容 | 実務での使いどころ | キャリア接続 |

| コスト・ヒューリスティック | 全部調べられないときの優先順位付け | PM/PLとして工数配分に直結 |
| αβ法の枝刈り | 無駄な確認・無駄なレビュー範囲を減らす考え方 | 生産性向上・工数削減の説明に使える |
| エキスパートシステム | 業務ルールをif-thenで整理する | 業務システム設計・ルールエンジン理解に有効 |
| 知識獲得のボトルネック | 顧客から暗黙知を引き出す難しさ | 要件定義・顧客折衝の核心 |
| オントロジー | 用語定義、データ辞書、マスタ設計 | 上流設計・データ設計で重要 |
| is-a/part-of | 継承関係、親子関係、構成関係の整理 | DB設計、クラス設計、業務概念整理に使える |
| 特徴量設計 | AI活用で「何のデータを使うべきか」を考える | DX/AI企画で必須 |
| 次元の呪い | データ項目を増やせばよいわけではない理解 | データ分析PoCの失敗回避 |
| ディープラーニング | 画像・音声・自然言語でなぜ強いかの理解 | AI活用提案の基礎 |
| LLM | ChatGPTや社内AI活用の原理理解 | AI活用人材として説明力が上がる |
| ファインチューニング | 汎用AIを業務向けに調整する考え方 | 社内AI導入・業務改善提案に直結 |

実務で使える一言：

- 「AIは魔法ではなく、探索・知識・データ学習の延長にある」
- 「業務AI導入で難しいのは、モデル以前に業務知識・データ・評価基準を整理すること」
- 「知識獲得のボトルネックは、要件定義の難しさとかなり近い」

## 9-2. ここまで分かれば合格寄り

第2章で高得点を狙うなら、次まで押さえる。

- AlphaGoは単なる全探索ではなく、ディープラーニングを活用した点が重要。
- Watsonは質問の意味を本当に理解しているのではなく、候補を検索・評価している。
- Cycは一般常識を取り込むプロジェクトで、現在も継続中。
- ビッグデータには固定の容量基準はない。
- レコメンデーションやスパムフィルタは、ビッグデータを利用した機械学習で実用化。
- SuperVisionはチーム名、AlexNetはモデル名。
- LLMの性能はパラメータ数だけでなく、データ量と計算リソースにも依存する。
